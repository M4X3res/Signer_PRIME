# Исправление критических багов Pipeline/Process Pool — Быстрый старт

## 🎯 Что исправлено

5 критических багов, из-за которых Pipeline не работал и Process Pool был медленным:

1. **Pipeline падал сразу** → исправлен `AttributeError` на `.bbox`
2. **Текст знаков не сохранялся** → OCR результат теперь пишется в `TrackedSign`
3. **Process Pool медленнее в 5-8 раз** → добавлен OCR-кэш (70-85% экономии)
4. **Названия городов всегда пустые** → исправлен `best_city_name()`
5. **Знаки в конце видео терялись** → добавлен `finalize_remaining()`
