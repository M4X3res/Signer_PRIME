# Модернизированный Installer с прогрессом скачивания

## ✨ Что нового

### Детальный прогресс скачивания

Теперь installer показывает:
- ✅ **Номер текущего файла** (Файл X из Y)
- ✅ **Процент текущего файла** (скачано/общий размер)
- ✅ **Общий процент установки** (от 0% до 100%)
- ✅ **Скорость скачивания** в реальном времени (МБ/с, КБ/с)
- ✅ **Размер файлов** в читаемом формате (ГБ, МБ, КБ)

### Пример отображения

```
Скачивание файлов
Пожалуйста, подождите пока установщик скачивает необходимые файлы...

Файл 15 из 42: Signer.7z.015
Размер: 100.00 МБ
Скорость: 8.45 МБ/с
Общий прогресс: 36%

[██████████████░░░░░░░░░░░░░░░░░] 36%
```

## 🔧 Техническая реализация

### Встроенная реализация (используется по умолчанию)

- Использует PowerShell + System.Net.WebClient
- Не требует внешних плагинов
- Автоматически рассчитывает скорость
- Форматирует размеры файлов
- Показывает прогресс-бар

### Преимущества

1. **Работает из коробки** - не нужен IDP
2. **Кросс-версионная** - совместима со всеми версиями Inno Setup 6.x
3. **Легковесная** - всё встроено в .iss файл
4. **Настраиваемая** - легко менять логику отображения

## 🎯 Особенности

### Автоматическое определение скорости

Скорость рассчитывается для каждого файла:
```pascal
Speed := (FileSize * 1000.0) / ElapsedTimeInMS
```

Форматируется автоматически:
- Более 1 МБ/с → `X.XX МБ/с`
- Более 1 КБ/с → `X.X КБ/с`
- Менее 1 КБ/с → `XXX Б/с`

### Форматирование размеров

```pascal
FormatBytes(4300000000) → "4.00 ГБ"
FormatBytes(100000000)  → "95.37 МБ"
FormatBytes(13700000)   → "13.07 МБ"
FormatBytes(4000)       → "3.9 КБ"
```

### Пропуск уже скачанных файлов

Если файл уже существует в `{tmp}\`:
```
✓ Файл уже существует: Signer.7z.015
```

Это ускоряет повторные попытки установки.

## 🔍 Отладка

### Тестирование прогресса

Для тестирования на маленьком файле временно измените:

```iss
#define SIGNER_PART_COUNT 1  ; Только первая часть

; И в InitializeWizard:
AddDownloadFile('{#RELEASE_BASE_URL}/Signer.7z.001', 'Signer.7z.001', 100000000);
AddDownloadFile('{#RELEASE_BASE_URL}/checksum.sha256', 'checksum.sha256', 4000);
```

### Просмотр реального времени

Запустите installer и наблюдайте:
- Прогресс-бар должен обновляться плавно
- Скорость должна быть стабильной (±20%)
- Процент должен расти от 0% до 100%

## 🎨 Кастомизация

### Изменить формат отображения

Отредактируйте в `DownloadFileWithProgress`:

```pascal
StatusMsg := Format(
  '📥 Файл %d/%d: %s' + #13#10 +
  '📊 Прогресс: %d%%' + #13#10 +
  '⚡ Скорость: %s' + #13#10 +
  '💾 Размер: %s',
  [FileIndex, TotalFiles, ExtractFileName(DestPath),
   FilePercent, FormatSpeed(Speed), FormatBytes(FileSize)]
);
```

### Добавить ETA (оставшееся время)

```pascal
if Speed > 0 then
  ETA := Round((TotalBytesToDownload - TotalBytesDownloaded) / Speed)
else
  ETA := 0;
  
ETAStr := Format('%d мин %d сек', [ETA div 60, ETA mod 60]);
```

## ⚠️ Известные ограничения

1. **Скорость обновления**: Прогресс обновляется после завершения каждого файла, а не в реальном времени во время скачивания одного файла
   - **Решение**: Для реального прогресса используйте IDP (см. `SETUP_IDP.md`)

2. **Без retry**: Если скачивание файла не удалось, нужно перезапустить установщик
   - **Решение**: Уже скачанные файлы пропускаются автоматически

3. **PowerShell зависимость**: Требуется PowerShell 3.0+ (есть в Windows 8+)
   - **Решение**: Для Windows 7 используйте IDP
