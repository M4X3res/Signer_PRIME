# Сводка изменений - SignerInstaller.iss

## Исправления

### ✅ Исправлена кнопка "Повторить загрузку"

**Проблема:** При прерывании загрузки и повторной попытке установщик мог зависать.

**Решение:** 
- Добавлен вызов `DownloadPage.Clear` перед каждой попыткой
- Список файлов пересобирается в начале каждой итерации retry-цикла
- Это официальный паттерн Inno Setup для страниц загрузки

## Новые функции

### 🆕 Добавлена загрузка опциональных компонентов

Восстановлена функциональность из `SignerInstaller_old.iss`:

1. **NVIDIA CUDA Toolkit** (~3 ГБ)
   - Автоопределение наличия в системе
   - Сетевой установщик, тихая установка

2. **FFmpeg** (~115 МБ)
   - Автоопределение в PATH
   - Распаковка в Program Files

3. **K-Lite Codec Pack** (~60 МБ)
   - Автоопределение через реестр
   - Тихая установка

### 📦 Типы установки

- **Полная** - Signer + все компоненты
- **Компактная** - только Signer
- **Выборочная** - ручной выбор

## Изменённые файлы

- `installer/SignerInstaller.iss` - основной файл установщика
- `installer/CHANGELOG_INSTALLER.md` - детальное описание изменений
- `installer/USAGE_GUIDE.md` - инструкция по использованию

## Как протестировать

```cmd
"%ProgramFiles(x86)%\Inno Setup 6\ISCC.exe" installer\SignerInstaller.iss
```

Тесты:
1. Полная установка (все компоненты)
2. Прерывание загрузки + повтор (2-3 раза)
3. Установка на системе с уже установленными компонентами
