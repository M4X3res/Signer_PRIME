## Как использовать

### Сборка установщика

```cmd
"%ProgramFiles(x86)%\Inno Setup 6\ISCC.exe" installer\SignerInstaller.iss
```

Перед сборкой обязательно обновите:
- `#define RELEASE_TAG "v2.0.0"` - на актуальный тег релиза
- `#define SIGNER_PART_COUNT 41` - на актуальное количество частей архива

### Типы установки

При запуске установщика пользователь может выбрать:

1. **Полная установка** - Signer + CUDA + FFmpeg + K-Lite
2. **Компактная** - только Signer
3. **Выборочная** - можно выбрать компоненты вручную

### Автоопределение компонентов

Установщик автоматически проверяет наличие компонентов:
- Если CUDA уже установлен - галочка снимается
- Если FFmpeg найден в PATH - галочка снимается
- Если K-Lite найден в реестре - галочка снимается

### Прерывание и повтор загрузки

Если загрузка прервалась (проблемы с интернетом, отмена пользователем):
1. Нажмите "Отмена" на странице загрузки
2. Появится диалог: "Повторить попытку загрузки?"
3. Нажмите "Да" - загрузка начнётся заново
4. Или "Нет" - установка будет отменена

**Важно:** Список файлов теперь полностью пересобирается перед каждой попыткой, что предотвращает зависания.

## Обновление URL компонентов

Если нужно обновить URL для CUDA, FFmpeg или K-Lite, отредактируйте константы в начале файла:

```pascal
; ──────────────────────────────────────────────────────────────────
; Optional components — URLs for additional downloads
; ──────────────────────────────────────────────────────────────────
#define CUDA_URL "https://developer.download.nvidia.com/compute/cuda/12.6.0/network_installers/cuda_12.6.0_windows_network.exe"
```

## Порядок установки

1. **Загрузка зависимостей** (InnoDependencyInstaller):
   - VC++ Redistributable
   - .NET Desktop Runtime 8
   - WebView2 Runtime
   - ODBC Driver 18

2. **Загрузка основных файлов**:
   - Signer.7z.001 .. Signer.7z.041 (41 часть, ~4 ГБ)
   - checksum.sha256
   - Опциональные компоненты (если выбраны)

3. **Проверка целостности** (SHA-256 для каждой части)

4. **Распаковка архива** (7-Zip, в Program Files)

5. **Установка опциональных компонентов**:
   - CUDA - тихая установка
   - FFmpeg - распаковка в Program Files
   - K-Lite - тихая установка

6. **Очистка временных файлов**

## Примечания

### CUDA
- Скачивается сетевой установщик (~3.2 МБ)
- Полная установка занимает ~3 ГБ
- Установка происходит в режиме `-s` (silent)

### FFmpeg
- Распаковывается в `C:\Program Files\ffmpeg\`
- Пользователю показывается сообщение о необходимости добавления в PATH:
  ```
  C:\Program Files\ffmpeg\bin
  ```

### K-Lite
- Устанавливается в режиме `/VERYSILENT /NORESTART`
- Регистрируется в системе через установщик

## Логирование

Все действия записываются в лог Inno Setup:
- Успешные загрузки: `✓ Downloaded: filename.ext`
- Успешная проверка SHA-256: `✓ Checksum verified: filename`
- Ошибки: `Warning:` или `Error:`

Лог можно найти в: `%TEMP%\Setup Log YYYY-MM-DD #NNN.txt`

## Требования к системе

- Windows 10 build 17763+ (October 2018 Update)
- Минимум 8.4 ГБ свободного места (временно)
- После установки: ~4.3 ГБ (основная программа)
- Права администратора
- Стабильное подключение к интернету
