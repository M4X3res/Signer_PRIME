Команды:

  build_test.bat
    → Быстрая тестовая сборка

  build_release.bat
    → Полная сборка релиза

  .\upload_release.ps1
    → Загрузка на GitHub (авто)

  .\upload_release.ps1 -Draft
    → Загрузка как черновик

  .\upload_release.ps1 -PreRelease
    → Загрузка как пре-релиз

Файлы конфигурации:

  version.json          → Версия приложения
  release_notes.txt     → Описание релиза
  signer.spec           → Настройки сборки основного приложения
  updater.spec          → Настройки сборки обновлятеля

Результаты:

  dist\Signer\          → Тестовая сборка
  release\              → Файлы для GitHub Release

Документация:

  QUICK_RELEASE_GUIDE.md  → Краткое руководство
