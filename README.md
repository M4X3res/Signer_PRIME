# RoadScanner (Signer PRIME)

Signer PRIME — Windows-приложение для обнаружения дорожных знаков на видео, привязки к GPS-треку и ручной проверки результатов.

## Быстрый запуск

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```
