# Placeholder для 7z.exe и 7z.dll

**ПРИМЕЧАНИЕ:** Эта директория изначально планировалась для хранения `7za.exe`, но теперь используется `7z.exe` и `7z.dll` из директории `installer\`.

Если вам нужно использовать отдельную копию 7-Zip:
- Скачайте 7-Zip с https://www.7-zip.org/download.html
- Установите 7-Zip
- Скопируйте `7z.exe` и `7z.dll` из `C:\Program Files\7-Zip\` в `installer\`

Эти файлы используются:
1. Inno Setup инсталлятором для распаковки релизов
2. Updater.exe для применения автообновлений
