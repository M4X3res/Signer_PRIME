# Архив скриптов разработки

Старые скрипты для разработки и тестирования, перемещённые из основной структуры проекта.

## Содержимое

### Экспорт моделей
- `export_models_onnx.py` — экспорт PyTorch моделей в ONNX формат

### Бенчмарки
- `benchmark_detector.py` — тестирование производительности детектора
- `benchmark_end_to_end_cpu.py` — полный бенчмарк на CPU

### Dev-скрипты (`dev/`)
Различные тестовые и диагностические скрипты для отладки:
- Тесты ONNX-моделей
- Диагностика координат и GPS
- Проверка бэкендов детекции
- Тесты UI-компонентов
- Анализ дубликатов и логирования

## Использование

Эти скрипты могут быть полезны для:
- Отладки моделей машинного обучения
- Тестирования производительности
- Диагностики проблем с детекцией
- Экспериментов с новыми функциями

Большинство скриптов требуют запуска из корневой директории проекта:
```bash
python scripts/archive/export_models_onnx.py
python scripts/archive/dev/test_import.py
```
