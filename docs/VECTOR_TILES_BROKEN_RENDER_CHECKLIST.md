## Корневая причина (найдена и задокументирована)

**Баг:** Пользователь вставил URL конкретного тайла вместо шаблона с плейсхолдерами.

**URL из бага:**
```
http://api.maps.by/.../tile/9/163/291.pbf?token=...&
                           ^^^^^^^^ НЕТ плейсхолдеров! + оборванный URL
```

**Правильный URL:**
```
http://api.maps.by/.../tile/{z}/{y}/{x}.pbf?token=...
                           ^^^^^^^^^^ Плейсхолдеры!
```

**Механизм бага:**
- Leaflet запрашивает разные координаты
- Сервер всегда возвращает тайл 9/163/291
- Результат: мозаика из одинаковых фигур
