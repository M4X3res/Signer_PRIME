## Что сделано

Добавлена **автоматическая загрузка стилей** для векторных тайлов.

Теперь при использовании api.maps.by карта отображается с **оригинальными цветами и стилями** провайдера вместо упрощённых generic-стилей.

---

## Как это работает

1. **Frontend** запрашивает `/api/vector_tile_style`
2. **Backend** формирует URL стилей: `base_url/resources/styles/root.json?token=...`
3. **Backend** проксирует запрос к api.maps.by с CORS-заголовками
4. **Frontend** парсит JSON и преобразует в Leaflet.VectorGrid формат
5. **Карта** отображается с оригинальными стилями

**Если стили недоступны:** автоматически используется fallback (generic styles).

## Пример URL

**Ваш URL:**
```
https://api.maps.by/.../tile/{z}/{y}/{x}.pbf?token=$2a$10$...ABC*$2a$10$...XYZ
```

**Автоматически извлекается base URL и формируется:**
```
https://api.maps.by/.../resources/styles/root.json?token=$2a$10$...ABC*$2a$10$...XYZ
```

**Стили загружаются и применяются автоматически!**
