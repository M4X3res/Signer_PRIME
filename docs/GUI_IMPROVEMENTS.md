# GUI Улучшения - 2026-07-09

## Изменения

### 1. ✅ Переключатель темы (Toggle Switch)

**Было:** Текст "переключить" с подчеркиванием (гиперссылка)

**Стало:** Красивый анимированный переключатель в стиле iOS/Material Design

**Файлы:**
- `ui/widgets/toggle_switch.py` - новый компонент переключателя
- `ui/widgets/sidebar.py` - заменена кнопка на переключатель

**Особенности:**
- Плавная анимация переключения (200ms, easing)
- Золотистый цвет для светлой темы (☀)
- Темно-серый для темной темы (☾)
- Белый кружок-переключатель

### 2. Про видео на странице карты

**Вопрос:** Почему справа пустое окно на вкладке "Карта"?

**Ответ:** На странице карты справа должна быть **интерактивная карта** (WebView), а не видео.

**Видео отображается на:**
- Вкладка "Обработка" (`ProcessingPage`) - там есть `video_label` для предпросмотра кадров

**Карта отображает:**
- WebView с Leaflet картой
- Загружается через локальный сервер на порту 5050
- Показывает GPS трек и обнаруженные знаки

### 3. Исправления кнопок

Текущие стили кнопок определены в:
- `ui/themes/dark_theme.py`
- `ui/themes/light_theme.py`

**Основные классы кнопок:**
- `BtnPrimary` - основная кнопка (синяя)
- `BtnSecondary` - вторичная кнопка (серая)
- `BtnIcon` - кнопка-иконка

**Если есть проблемы с кнопками** - опишите конкретно какие и где.

## Тестирование

1. Запустите приложение
2. Проверьте переключатель темы внизу sidebar
3. Переключите между светлой и темной темой
4. Проверьте что все элементы перекрашиваются корректно
