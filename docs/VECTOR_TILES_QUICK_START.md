# Быстрая инструкция: Использование векторных тайлов с CORS-прокси

## Для пользователей api.maps.by и других Esri-серверов

Векторные тайлы теперь работают "из коробки" благодаря встроенному CORS-прокси.

### ✅ Настройка (рекомендуется)

1. Откройте **Настройки** → **Карта**

2. Выберите тип подложки:
   ```
   ☑ Векторные тайлы (.pbf, Mapbox Vector Tiles)
   ```

3. Вставьте URL вашего провайдера:
   ```
   http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=ВАШ_ТОКЕН
   ```
   
   ⚠️ **Важно:** Для api.maps.by порядок координат `{z}/{y}/{x}`, а не `{z}/{x}/{y}`!

4. Убедитесь что прокси включён (по умолчанию):
   ```
   ☑ Прокси для векторных тайлов ✅ Включено
   ```

5. Нажмите **💾 Сохранить**

6. Откройте **Карту** — векторные тайлы должны отображаться

### Как это работает

**С прокси (дефолт):**
```
Ваш браузер → http://127.0.0.1:3000/api/vector_tile_proxy/9/163/291
              ↓
Локальный сервер → http://api.maps.by/.../tile/9/163/291.pbf?token=...
              ↓
Ответ с CORS-заголовками → Ваш браузер → Карта отображается ✅
```

**Без прокси (если провайдер поддерживает CORS):**
```
Ваш браузер → напрямую к api.maps.by
              ↓
❌ CORS блокировка (для большинства Esri-серверов)
```

### Отключение прокси (опционально)

Если ваш провайдер тайлов поддерживает CORS (редко), можно выключить прокси:

1. **Настройки** → **Карта**
2. **Прокси для векторных тайлов** → ❌ Выключить
3. **Сохранить**

⚠️ Для api.maps.by прокси **обязателен** — без него карта будет пустой.

### Проверка работы

**Если тайлы НЕ отображаются:**

1. Откройте карту → **"⬡ В браузере"**
2. Нажмите **F12** (DevTools)
3. Перейдите на вкладку **Console**

**Ищите:**
```
[loadTileLayer] Config loaded: {tile_type: "vector", ...}
[loadTileLayer] Creating vector tile layer...
[VectorGrid] Tile loaded: {x: 163, y: 291, z: 9}
```

**Если видите ошибки:**
```
[VectorGrid] Tile error: ...
```
→ Проверьте токен в настройках (возможно просрочен)

**Вкладка Network:**
- Найдите запросы к `/api/vector_tile_proxy/...`
- Проверьте статус: должен быть **200 OK**
- Если **401/403** → токен невалидный
- Если **404** → проверьте порядок координат в URL

### Безопасность

✅ **Ваш токен надёжно защищён:**
- Не передаётся в браузер (остаётся на локальном сервере)
- Не виден в DevTools → Network → Response
- Маскируется в логах: `token=****XYZ`

### Растровые тайлы (OSM и другие)

Растровые тайлы работают как раньше, прокси не используется:

```
☑ Растровые тайлы (PNG/JPG)
URL: https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
```

Прокси влияет **только на векторные тайлы**.

### Примеры URL

#### ✅ Правильно (api.maps.by):
```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=ВАШ_ТОКЕН
```
Обратите внимание: `{z}/{y}/{x}` (не x/y!)

#### ✅ Правильно (другой Mapbox-совместимый сервер):
```
https://tiles.example.com/{z}/{x}/{y}.pbf?key=API_KEY
```

#### ❌ Неправильно (расширение не .pbf):
```
https://tiles.example.com/{z}/{x}/{y}.png
```
→ Это растровые тайлы, выберите соответствующий тип

### Устранение проблем

| Проблема | Решение |
|----------|---------|
| Карта пустая | Проверьте токен (может быть просрочен) |
| HTTP 401/403 | Получите новый токен на сайте провайдера |
| HTTP 404 | Проверьте порядок {x}/{y} vs {y}/{x} |
| "blocked by CORS" | Убедитесь что прокси включён (дефолт) |
| Тайлы не рисуются (но загружаются) | Возможна несовместимость Esri-формата, используйте растровые тайлы |

### Получение токена для api.maps.by

1. Зарегистрируйтесь на https://api.maps.by/
2. Получите API-ключ (токен) в личном кабинете
3. Скопируйте токен полностью (обычно это длинная строка)
4. Вставьте в URL вместо `ВАШ_ТОКЕН`

⚠️ **Важно:** Скопируйте токен без пробелов и лишних символов.
