# 🚀 Параллельные детекторы — Быстрый старт

## Что это?

Пул из 2-4 параллельных детекторов для **максимального использования многоядерных CPU**. Даёт **2-3x ускорение**.

## Использование

### Автоматически работает!

По умолчанию **включено** и автоматически определяет оптимальное количество воркеров:

| Ваш CPU | Воркеров | Ускорение |
|---------|----------|-----------|
| 2 ядра | 1 (отключён) | 1x |
| 4 ядра | 2 | **2-2.5x** |
| 6 ядер | 3 | **2.5-3x** |
| 8+ ядер | 4 | **3-3.5x** |

### Результаты

**На 4-ядерном CPU:**

```
Было:  23.5 FPS (4.2 мин на 10 мин видео)
Стало: ~50 FPS  (~2 мин на 10 мин видео)

Ускорение: 2.1x
```

**Суммарно со всеми оптимизациями:**

```
Базовая:             5.2 FPS  (19 мин)
+ Smart Skipping:   15.8 FPS  (6.3 мин)
+ CNN Cache:        23.5 FPS  (4.2 мин)
+ Detector Pool:    ~50 FPS   (~2 мин)

Итого: 9.5x ускорение! 🎉
```

## Как работает

```
VideoReaderThread → frame_queue
                        ↓
    ┌──────────────────┴──────────────────┐
    │                                     │
Worker #1 (детектирует)    Worker #2 (детектирует)
    │                                     │
    └──────────────────┬──────────────────┘
                       ↓
            AggregatorThread
             (SignHandler)
                       ↓
               result_queue
```

**Work stealing:** Воркеры забирают кадры из общей очереди → автоматическая балансировка!

## Требования

### ✅ Рекомендуется

- **4+ ядра CPU**
- **8+ ГБ RAM** (лучше 16 ГБ)
- **Долгая обработка** (десятки видео)

### ❌ НЕ рекомендуется

- **2 ядра** (нет прироста)
- **< 6 ГБ RAM** (риск нехватки памяти)
- **Laptop на батарее** (быстрый разряд)

### Память

Каждый воркер загружает модели (~2 ГБ):

| Воркеров | Память на модели |
|----------|------------------|
| 1 (отключён) | 2 ГБ |
| 2 | **4 ГБ** |
| 3 | **6 ГБ** |
| 4 | **8 ГБ** |

## Настройки

### В UI

**Настройки → Обработка видео → Параллельные детекторы**

- ✓ Включено (по умолчанию)
- Автоопределение воркеров

### Вручную (env)

```bash
# Явно указать количество воркеров
export DETECTOR_WORKERS=3
python main.py
```

### Отключение

**Через UI:** Убрать галочку "Параллельные детекторы"

**Через код:**
```python
# processing/processing_controller.py
USE_DETECTOR_POOL = False
```

## Troubleshooting

### "FPS не увеличивается"

1. Проверьте CPU (должно быть 4+ ядра)
2. Проверьте загрузку CPU (должна быть 50-70%)
3. Возможно bottleneck в VideoReader (медленный HDD?)

### "Недостаточно памяти"

1. Уменьшите воркеров через `DETECTOR_WORKERS=2`
2. Или отключите пул (используйте одиночный детектор)
3. Закройте другие приложения

### "Воркеры не запускаются"

1. Проверьте логи на ошибки загрузки моделей
2. Убедитесь что есть свободная RAM (минимум 4 ГБ)
