# Быстрый старт - Карта и обработка видео

## Запуск обработки

1. **Запустите приложение**
   ```bash
   python main.py
   ```

2. **Выберите видео и GPX** в Dashboard

3. **Нажмите "Начать обработку"**
   - Модели загрузятся автоматически
   - Сервер карты запустится на порту 3000
   - Обработка начнется

## Использование карты во время обработки

### Live режим (в реальном времени)

1. **Откройте вкладку "Карта"**
2. **Нажмите кнопку "⬤ Live"**
   - Зеленая точка = Live режим активен
   - Маркер текущей позиции появится на карте
   - Карта будет автоматически центрироваться

3. **Что видно в Live режиме:**
   - 🔴 Маркер текущей позиции движется по треку
   - 📍 Новые знаки появляются сразу после детекции
   - 📊 Статистика обновляется в реальном времени
   - 🔔 Toast уведомления о новых знаках

### Управление обработкой

#### Пауза
```
Кнопка "⏸ Пауза" → обработка приостанавливается
Кнопка меняется на "▶ Продолжить"
```

#### Завершение
```
Кнопка "■ Завершить" → 
  1. Обработка завершается корректно
  2. GeoJSON сохраняется
  3. Карта автоматически обновляется
  4. Все функции доступны
```

## Работа с картой после обработки

### Просмотр знаков

1. **Клик на маркер знака** → правая панель покажет детали:
   - Тип знака и название
   - Время, видео, азимут, сторона
   - Изображение знака

2. **Редактирование знака:**
   - Измените тип в dropdown
   - Введите текст (если применимо)
   - Нажмите "✓ Сохранить"

3. **Переход к кадру:**
   - Нажмите "⏩ К кадру"
   - Приложение перейдет к моменту детекции знака

4. **Удаление знака:**
   - Нажмите "✕"
   - Подтвердите удаление

### Фильтрация

**По типу знака:**
```
Введите в поиск → "3.24" или "запрещ"
Маркеры отфильтруются автоматически
```

**По стороне:**
```
Клик на чип "Лево" → только знаки слева
Клик на чип "Право" → только знаки справа
Клик на чип "Все" → сброс фильтра
```

### Навигация по карте

| Кнопка | Действие |
|--------|----------|
| **По треку** | Центрирует карту на GPS треке |
| **Трек** | Показать/скрыть линию GPS трека |
| **Live** | Включить/выключить режим реального времени |
| **↓ GeoJSON** | Скачать результаты в формате GeoJSON |

## Видеоплеер на карте

**Управление:**
- `«` - на 10 секунд назад
- `▷` / `⏸` - воспроизведение/пауза
- `»` - на 10 секунд вперед
- Слайдер - перемотка

**Синхронизация:**
- Движение слайдера → обновление позиции на карте
- Jump из знака → слайдер устанавливается автоматически

## Горячие клавиши (планируется)

- `Space` - пауза/продолжить
- `←` / `→` - шаг назад/вперед
- `L` - toggle Live режима
- `Esc` - закрыть панель деталей знака

## Открыть карту в браузере

Нажмите **"⬡ В браузере"** чтобы открыть карту в отдельном окне браузера:
```
http://localhost:3000
```

## Проблемы и решения

### Карта не загружается

**Проблема:** "Не удалось загрузить карту"

**Решение:**
1. Проверьте логи в консоли Processing
2. Убедитесь что сервер запущен (порт 3000)
3. Перезагрузите карту кнопкой "↺ Перезагрузить"

### Нет знаков на карте

**Проблема:** Карта пустая после обработки

**Решение:**
1. Проверьте что обработка завершена (не прервана)
2. Проверьте файл `output/signs.geojson`
3. Нажмите "↺ Перезагрузить" на карте
4. Проверьте логи на ошибки сохранения

### Live режим не работает

**Проблема:** Маркер позиции не двигается

**Решение:**
1. Убедитесь что обработка активна
2. Проверьте соединение WebSocket (F12 → Console)
3. Проверьте что GPX файл загружен корректно
4. Выключите и включите Live режим снова

### Медленная работа карты

**Проблема:** Карта тормозит при большом количестве знаков

**Решение:**
1. Используйте фильтры для уменьшения количества маркеров
2. Скройте GPS трек кнопкой "Трек"
3. Увеличьте зум карты (меньше маркеров в видимости)
4. Рассмотрите кластеризацию маркеров (в разработке)

## Расширенные возможности

### Экспорт результатов

1. **GeoJSON** - нажмите "↓ GeoJSON"
   - Формат для GIS приложений (QGIS, ArcGIS)
   - Содержит геометрию и атрибуты

2. **В браузере** - откройте карту в браузере
   - Можно использовать DevTools для отладки
   - Копировать данные через Console

### Интеграция с внешними системами

**API доступно по адресу:**
```
http://localhost:3000/api/
```

**Примеры запросов:**
```bash
# Получить все знаки
curl http://localhost:3000/api/signs

# Получить GPS трек
curl http://localhost:3000/api/track

# Обновить знак
curl -X PATCH http://localhost:3000/api/sign/<id> \
  -H "Content-Type: application/json" \
  -d '{"type":"3.24","description":"50"}'
```

## Советы для эффективной работы

1. **Используйте Live режим** только когда нужно следить в реальном времени
2. **Фильтруйте знаки** для быстрого поиска нужных
3. **Группируйте редактирование** - исправьте все знаки за раз
4. **Сохраняйте промежуточные результаты** - экспортируйте GeoJSON периодически
5. **Используйте Jump to Frame** для проверки сомнительных детекций
