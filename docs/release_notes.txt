Signer PRIME v2.0.1

Исправления сборки и обновлений:
- Все 18 YOLO-моделей проверяются внутри собранного EXE на CPU и, при наличии, CUDA.
- Веса OCR включены в дистрибутив; при работе программы не требуется скачивать их отдельно.
- Исправлены комплектность CPU-backend, конфликт ICU/Qt и расположение кешей моделей.
- Манифест установленной версии включён в архив для полного и дельта-обновления.
- Публикация выполняется после проверки всех файлов в черновике релиза.
- Защищённые установки обновляются через UAC.
- Исправлены поворот знака колесом мыши и кнопка рекомендуемых настроек.

## 🚀 Новые возможности

### CPU-оптимизация: ONNX Runtime и OpenVINO
Добавлена полная поддержка альтернативных CPU-инференс бэкендов для улучшенной производительности на системах без NVIDIA GPU:

- **ONNX Runtime** - оптимизированный инференс на CPU (до 2-3x быстрее стандартного PyTorch CPU)
- **OpenVINO** - Intel-оптимизированный инференс (особенно эффективен на процессорах Intel)

**Как использовать:**
1. Откройте приложение
2. Перейдите в Settings → Performance
3. В разделе "CPU Inference Backend" выберите:
   - **ONNX Runtime** (рекомендуется для большинства систем)
   - **OpenVINO** (рекомендуется для Intel CPU)
   - PyTorch (по умолчанию, если у вас есть CUDA GPU)

**Улучшение производительности:**
- На CPU-only системах: до 2-3x ускорение классификации знаков
- Меньшее потребление памяти
- Более стабильная работа на старых системах

## 📋 Системные требования

- Windows 10/11 (64-bit)
- 8+ GB RAM (рекомендуется 16 GB)
- 5+ GB свободного места на диске
- **Для GPU-ускорения:** NVIDIA GPU с поддержкой CUDA (опционально)
- **Для CPU-режима:** любой современный процессор (Intel/AMD)

## 📦 Установка

### Первая установка
1. Скачайте все файлы `Signer.7z.001`, `Signer.7z.002`, `Signer.7z.003`, ... в одну папку
2. Распакуйте первый файл (`Signer.7z.001`) с помощью 7-Zip
3. Запустите `Signer.exe`

### Обновление с предыдущей версии
**Автоматическое обновление (рекомендуется):**
1. Запустите текущую версию Signer PRIME
2. Откройте Settings → Check for updates
3. Следуйте инструкциям на экране

**Ручное обновление:**
1. Закройте Signer PRIME
2. Удалите старую папку с приложением (или переименуйте для резервной копии)
3. Распакуйте новую версию
4. Запустите `Signer.exe`

**Примечание:** Ваши настройки сохранятся автоматически (хранятся в реестре Windows).

## 🐛 Известные ограничения

- Delta-обновления (дифференциальные) не поддерживаются для обновления с v2.0.0 (будет скачан полный архив)
- После обновления нужно вручную переключить CPU Inference Backend в настройках для получения улучшенной производительности

## 🔍 Проверка целостности

После скачивания проверьте SHA-256 чексуммы:

**Windows (PowerShell):**
```powershell
Get-FileHash Signer.7z.001 -Algorithm SHA256
```

Сравните с содержимым файла `checksum.sha256`.
