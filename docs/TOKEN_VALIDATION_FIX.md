## Проблема

При первоначальной реализации исправления "мозаичной" карты была добавлена проверка символа `*` в токене как признака "двух склеенных bcrypt-токенов".

**Ошибочная логика:**
```python
if '*' in tile_url:
    if re.search(r'\$2[aby]\$\d+\$[^\*]+\*\$2[aby]\$\d+\$', tile_url):
        suspicious_patterns.append(
            "ДВА склеенных bcrypt-токена через '*'"
        )
```

**Проблема:** Символ `*` является **валидной частью токена**, который выдаёт api.maps.by. Эта эвристика блокировала корректные URL.

---

## Решение

Удалена проверка символа `*` как признака ошибки из `ui/widgets/settings_page.py`.

### Что осталось (валидные проверки):

#### Блокирующие ошибки:
1. **Отсутствие плейсхолдеров** `{z}`, `{x}`, `{y}` — **КРИТИЧЕСКАЯ** (основная причина "мозаики")
2. **Оборванный URL** — заканчивается на `&`, `?`, `=` без последующего параметра

#### Предупреждения (не блокируют):
1. **Пробелы** в URL
2. **Дублирование** параметра `token=` (несколько вхождений)
3. **Двойные амперсанды** `&&`

### Что убрано:

❌ Проверка на символ `*` в токене  
❌ Regex-детекция "двух bcrypt через `*`"  
❌ Предупреждение "ДВА склеенных bcrypt-токена"

### 1. `ui/widgets/settings_page.py`

**Было:**
```python
# Проверка 2: Символ * (признак склеенных токенов)
if '*' in tile_url:

        suspicious_patterns.append(
            "ДВА склеенных bcrypt-токена через '*' (явно некорректный токен)"

        suspicious_patterns.append("символ '*' (возможно склеенные токены)")
```

**Стало:**
```python
# Проверка убрана — символ * валиден для api.maps.by
```

**Добавлено в docstring:**
```python
"""
ВАЖНО: Символ '*' внутри значения token= сам по себе НЕ является признаком ошибки

"""
```

## Корневая проблема остаётся неизменной

**Главная причина "мозаики":** URL без плейсхолдеров `{z}/{x}/{y}`.

Эта проверка **не изменилась** и продолжает блокировать сохранение:

```python
if tile_type == "vector":
    has_z = '{z}' in tile_url
    has_x = '{x}' in tile_url
    has_y = '{y}' in tile_url
    
    if not (has_z and has_x and has_y):
        # ❌ БЛОКИРУЮЩАЯ ОШИБКА
        raise ValueError("Vector tile URL validation failed: missing placeholders")
```
