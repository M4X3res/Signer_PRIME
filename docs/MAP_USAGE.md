# Исправление отображения карты

## Проблема
После обработки видео знаки не отображаются на карте.

## Причина
Карта не перезагружалась автоматически после сохранения GeoJSON файла.

## Решение

### 1. Добавлена автоматическая перезагрузка карты

**В `ui/main_window.py` → `_save_results()`:**
```python
# Перезагружаем карту чтобы показать результаты
self.page_map._reload_map()
```

Теперь после завершения обработки карта автоматически перезагружается и показывает все обнаруженные знаки.

## Как использовать карту

### Основные элементы:

1. **Топбар (вверху):**
   - `⬤ Live` - включить режим реального времени (во время обработки)
   - `◐ Трек` - показать/скрыть GPS трек
   - `⊙ Центр` - отцентрировать карту на треке
   - `↓ GeoJSON` - скачать результаты

2. **Правая панель:**
   - Фильтры по типу знака
   - Фильтр по стороне (Левая/Правая/Обе)
   - Поиск по тексту на знаке
   - Детали выбранного знака

3. **Статистика:**
   - Количество точек GPS
   - Количество знаков
   - Режим (Live/Статика)

### Режимы работы:

**1. Статический режим (после обработки):**
- Показывает все обнаруженные знаки
- Можно кликать на маркеры для просмотра деталей
- Работают все фильтры
- Можно редактировать знаки (если реализовано)

**2. Live режим (во время обработки):**
- Включается кнопкой `⬤ Live`
- Зеленый индикатор показывает активный режим
- Знаки появляются в реальном времени
- Отображается текущая позиция обработки

## Workflow:

1. **Настройте пути** на странице Dashboard:
   - Папка с видео
   - GPX файл
   - GeoJSON для сохранения

2. **Запустите обработку:**
   - Нажмите "Начать обработку"
   - Перейдите на вкладку "Карта"
   - Включите Live режим если хотите видеть процесс

3. **После обработки:**
   - Карта автоматически перезагрузится
   - Все знаки отобразятся на карте
   - Используйте фильтры для поиска
   - Экспортируйте GeoJSON при необходимости

## Проверка:

✅ **Карта загружается** - видна базовая карта OpenStreetMap
✅ **GPS трек отображается** - синяя линия на карте
✅ **Знаки показываются** - маркеры с иконками знаков
✅ **Кнопки работают** - Live, Трек, Центр
✅ **Фильтры работают** - можно отфильтровать знаки
✅ **Детали показываются** - клик на знак открывает панель справа

## Если карта пустая:

1. **Проверьте путь к GeoJSON:**
   ```python
   # В Dashboard должен быть указан путь
   config.PATH_TO_GEOJSON = "путь/к/result.geojson"
   ```

2. **Проверьте что обработка завершилась:**
   - В логах должно быть "Сохранено N знаков в GeoJSON"
   - Файл GeoJSON должен существовать и не быть пустым

3. **Перезагрузите карту вручную:**
   - Кнопка "↺ Перезагрузить" в топбаре карты

4. **Проверьте консоль браузера:**
   - F12 → Console
   - Смотрите ошибки загрузки данных
