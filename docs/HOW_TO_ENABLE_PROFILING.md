# 🎯 Как включить профилирование через UI

## Быстрый старт

1. **Запустите приложение:**
   ```bash
   python main.py
   ```

2. **Откройте Настройки:**
   - Кликните на иконку шестеренки ⚙️ в боковой панели слева
   - Или нажмите на вкладку "Настройки"

3. **Прокрутите вниз до секции "Отладка и производительность"**

4. **Включите профилирование:**
   - Переключатель "Профилирование" → ON (●)
   - При включении автоматически активируется `core.profiler`

5. **Настройте частоту отчетов (опционально):**
   - По умолчанию: каждые 500 кадров
   - Можно изменить от 100 до 2000 кадров
   - Для быстрых тестов: 100 кадров
   - Для длинных видео: 1000-2000 кадров

6. **Начните обработку видео:**
   - Вернитесь в Dashboard
   - Выберите видео и GPX
   - Нажмите "Начать обработку"

7. **Смотрите результаты:**
   - Отчеты печатаются в консоль каждые N кадров
   - Также записываются в `roadscan.log`

## Анализ результатов

### Что искать:

1. **Узкие места** - операции с максимальным Total (суммарное время)
2. **Нестабильность** - большая разница между Min и Max
3. **Частые операции** - высокий Count с малым Mean может быть проблемой
4. **P95 vs Mean** - если P95 намного больше Mean, есть выбросы

### Типичные находки:

- **OCR долгий** → батчинг или параллелизм
- **classify_rube много раз** → батчинг поможет
- **video_read_frame медленный** → узкое место I/O
- **sign_handler_tracking долгий** → оптимизация трекинга

## Дополнительные настройки (в той же секции)

### Режим обработки:
- **Один поток** (по умолчанию) - текущая реализация
- **Пул процессов** (BETA) - многопроцессная обработка
- **GPU батчинг** (BETA) - оптимизация для GPU

### Количество воркеров:
- Авто-определение: `cpu_count - 1`
- Вручную: от 1 до 16 воркеров
- Применяется только для "Пул процессов"

## Сохранение отчета

После завершения обработки:

1. Отчет остается в `roadscan.log`
2. Скопируйте релевантные секции в `docs/PROFILING.md`
3. Добавьте комментарии о конфигурации:
   - CPU/GPU
   - Разрешение видео
   - Количество знаков на кадр
   - FPS обработки

## Отключение профилирования

1. Вернитесь в Настройки
2. Профилирование → OFF (○)
3. Или просто закройте приложение

## Следующие шаги после профилирования

На основе данных профилирования:

1. **Если OCR узкое место:**
   - Рассмотреть батчинг OCR
   - Или параллелизм на уровне OCR

2. **Если классификация узкое место:**
   - Реализовать батчинг в `Detector.detect()`
   - Группировать вызовы моделей

3. **Если CPU-bound:**
   - Переходить на "Пул процессов"
   - Установить оптимальное N_WORKERS

4. **Если GPU-bound:**
   - Переходить на "GPU батчинг"
   - Оптимизировать размер батча

## Troubleshooting

**Отчеты не появляются:**
- Убедитесь что обработано минимум 1000 кадров (`PROFILING_MIN_FRAMES`)
- Проверьте что включен переключатель
- Смотрите `roadscan.log` напрямую

**Слишком много отчетов:**
- Увеличьте "Частоту отчетов" до 1000-2000

**Производительность упала:**
- Профилирование добавляет ~1-2% накладных расходов
- Это нормально, выключите после сбора данных
