# Умный Frame Skipping

## Обзор

Умный frame skipping — это адаптивная система пропуска кадров, которая автоматически регулирует частоту обработки в зависимости от:
1. **Скорости движения автомобиля** — чем быстрее едем, тем больше можно пропустить
2. **Активности детекций** — если знаков много, сканируем чаще

## Преимущества

✅ **Ускорение обработки в 2-3 раза** без потери точности  
✅ **Экономия ресурсов CPU/GPU** — меньше кадров через нейросети  
✅ **Адаптивность** — автоматически подстраивается под условия  
✅ **Сохранение качества** — не пропускаем важные знаки  

## Как это работает

### 1. Базовый интервал по скорости

Система использует таблицу интервалов пропуска:

| Скорость | Интервал | Пояснение |
|----------|----------|-----------|
| 0-30 км/ч | Каждый 1-2 кадр | Город — знаков много, едем медленно |
| 30-60 км/ч | Каждый 2-3 кадр | Загород — баланс |
| 60-90 км/ч | Каждый 3-4 кадр | Трасса — едем быстро |
| 90+ км/ч | Каждый 4-5 кадр | Высокая скорость — знаки далеко |

Интервал вычисляется **линейной интерполяцией** между точками.

### 2. Модификатор активности

Система отслеживает последние 10 обработанных кадров:

- **Много знаков** (≥3 за последние 10 кадров) → **уменьшаем интервал на 1** (сканируем чаще)
- **Нет знаков** (0 за последние 10 кадров) → **увеличиваем интервал на 1** (экономим ресурсы)
- **Нормально** → без изменений

### 3. Финальное решение

```python
final_skip = base_skip + activity_modifier
final_skip = max(1, min(5, final_skip))  # Ограничиваем 1..5
```

## Примеры работы

### Пример 1: Город с активностью
- Скорость: 40 км/ч → базовый интервал = 2
- Найдено 4 знака за последние 10 кадров → модификатор = -1
- **Итого: каждый 1-й кадр** (все подряд)

### Пример 2: Трасса без знаков
- Скорость: 110 км/ч → базовый интервал = 4
- Нет знаков за последние 10 кадров → модификатор = +1
- **Итого: каждый 5-й кадр** (максимальная экономия)

### Пример 3: Загород с редкими знаками
- Скорость: 70 км/ч → базовый интервал = 3
- 1-2 знака за последние 10 кадров → модификатор = 0
- **Итого: каждый 3-й кадр** (баланс)

## Настройки

Настройки доступны в `processing/detector_thread.py`:

```python
class DetectorThread:
    # Базовые интервалы по скорости
    SKIP_INTERVALS = {
        0:   (1, 1),   # стоим
        30:  (1, 2),   # город
        60:  (2, 3),   # загород
        90:  (3, 4),   # трасса
        120: (4, 5),   # высокая скорость
    }
    
    # Коэффициенты адаптации
    ACTIVITY_WINDOW = 10         # кадров для анализа
    HIGH_ACTIVITY_THRESHOLD = 3  # знаков = высокая активность
    ACTIVITY_BONUS = -1          # уменьшаем skip при активности
    NO_ACTIVITY_PENALTY = 1      # увеличиваем skip без активности
```

### Как настроить под свои нужды

**Хотите более агрессивный skipping (быстрее, но риск пропустить знаки):**
```python
SKIP_INTERVALS = {
    0:   (1, 2),
    30:  (2, 3),
    60:  (3, 4),
    90:  (4, 5),
    120: (5, 6),
}
```

**Хотите консервативный режим (медленнее, но надёжнее):**
```python
SKIP_INTERVALS = {
    0:   (1, 1),
    30:  (1, 1),
    60:  (1, 2),
    90:  (2, 3),
    120: (3, 4),
}
```

**Отключить адаптацию по активности:**
```python
def _calc_activity_modifier(self) -> int:
    return 0  # всегда возвращаем 0
```

## Мониторинг

Система выводит статистику каждую секунду:

```
[SmartSkip] Обработано: 124, Пропущено: 248 (66.7%), Текущий интервал: 1/3, FPS: 15.2
```

Где:
- **Обработано** — кадров прошло через детектор
- **Пропущено** — кадров пропущено
- **%** — процент пропуска
- **Текущий интервал** — сейчас обрабатывается каждый N-й кадр
- **FPS** — скорость обработки

## FAQ

**Q: Не пропустим ли мы важные знаки?**  
A: Нет. Система адаптируется — при высокой активности детекций интервал уменьшается до 1 (все кадры).

**Q: Можно ли отключить?**  
A: Да, в настройках переключатель "Умный frame skipping".

**Q: Работает ли с несколькими видео?**  
A: Да, состояние сохраняется между видео в одной сессии обработки.

**Q: Влияет ли на трекинг знаков?**  
A: Нет, SignHandler корректно обрабатывает пропуски кадров.
