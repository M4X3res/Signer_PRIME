# Changelog — Умный Frame Skipping

## [1.0.0] - 2026-07-09

### ✨ Добавлено

#### Умный Frame Skipping
- **Адаптивный пропуск кадров** на основе скорости и активности детекций
- **Двухуровневая система**:
  1. Базовый интервал по скорости (линейная интерполяция)
  2. Модификатор по истории детекций (последние 10 кадров)
- **Автоматическая подстройка** — система сама выбирает оптимальный интервал 1-5 кадров
- **Мониторинг в реальном времени** — статистика каждую секунду в консоли

#### Настройки UI
- Переключатель "Умный frame skipping" в разделе "Обработка видео"
- Настройка "Минимум наблюдений" (1-15 кадров)
- Старый "Шаг кадра" помечен как устаревший

### 🐛 Исправлено

#### `core/sign_handler.py` (предыдущий коммит)

  - `_remove_lost_signs()` — строка 267
  - `_finalize_signs()` — строка 285
  - `_is_duplicate()` — строка 328
  - `_separate_turn_signs()` — строка 360
- **Проблема**: знаки с нестабильной классификацией не сохранялись, даже если были видны достаточно кадров

### 🎯 Сценарии использования

#### Город (30-50 км/ч, много знаков)
- Базовый интервал: 1-2 кадра
- При активности: каждый кадр
- Экономия: ~30-40%

#### Загород (50-80 км/ч, средняя плотность)
- Базовый интервал: 2-3 кадра
- Адаптивная подстройка: ±1 кадр
- Экономия: ~50-60%

#### Трасса (80-120 км/ч, мало знаков)
- Базовый интервал: 3-5 кадров
- При отсутствии знаков: каждый 5-й
- Экономия: ~70-80%

### 📝 Технические детали

**Алгоритм:**
1. Получить скорость из GPS
2. Интерполировать базовый интервал по таблице `SKIP_INTERVALS`
3. Проанализировать последние 10 кадров на наличие детекций
4. Применить модификатор активности (-1, 0, +1)
5. Ограничить финальное значение диапазоном [1, 5]
6. Инкрементировать счётчик, пропускать или обрабатывать

**Константы (настраиваемые):**
```python
SKIP_INTERVALS = {
    0: (1,1), 30: (1,2), 60: (2,3), 90: (3,4), 120: (4,5)
}
ACTIVITY_WINDOW = 10          # кадров истории
HIGH_ACTIVITY_THRESHOLD = 3   # знаков для "активности"
ACTIVITY_BONUS = -1           # уменьшение при активности
NO_ACTIVITY_PENALTY = 1       # увеличение при пустоте
```
