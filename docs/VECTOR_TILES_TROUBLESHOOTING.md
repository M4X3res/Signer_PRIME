# Диагностика проблем с векторными тайлами

Если векторные тайлы не отображаются на карте, следуйте этой инструкции.

## Быстрая диагностика

### 1. Проверьте консоль браузера

**Как открыть:**
1. На странице Карты нажмите кнопку **"⬡ В браузере"**
2. В открывшемся окне Chrome нажмите **F12**
3. Перейдите на вкладку **Console**

**Что искать:**

✅ **Успешная загрузка:**
```
[loadTileLayer] Config loaded: {tile_type: "vector", ...}
[loadTileLayer] Creating vector tile layer...
[VectorGrid] Tile loaded: {x: 163, y: 291, z: 9}
[loadTileLayer] ✅ Test tile available (HTTP 200)
```

❌ **Ошибки:**
```
[VectorGrid] Tile error: {coords: {...}, error: "..."}
[VectorGrid] Failed tile URL: http://...
[loadTileLayer] ❌ FATAL ERROR - Fallback to OSM
```

### 2. Частые проблемы и решения

#### Проблема: "HTTP 401" или "HTTP 403"

**Причина:** Неверный или просроченный токен API

**Решение:**
1. Откройте **Настройки** → **Карта**
2. Проверьте токен в URL:
   - Скопирован полностью (без обрезки)
   - Нет лишних пробелов
   - Нет символа `*` (склеенные токены)
   - Только один параметр `token=`
3. Получите новый токен на сайте провайдера
4. Вставьте новый токен и сохраните

#### Проблема: "CORS blocked"

**Причина:** Браузер блокирует cross-origin запросы

**Решение:** Активировать серверный прокси

1. Закройте приложение
2. Откройте файл `server/map_server.py`
3. Найдите строку:
   ```python
   use_proxy = False  # Флаг для будущего расширения
   ```
4. Измените на:
   ```python
   use_proxy = True
   ```
5. Сохраните файл и запустите приложение

#### Проблема: Тайлы не загружаются вообще

**Причина:** URL неверный или некорректный порядок координат

**Решение:**
1. Проверьте порядок `{z}/{x}/{y}` vs `{z}/{y}/{x}`
2. Для api.maps.by используйте `{z}/{y}/{x}`
3. Сверьтесь с документацией провайдера

**Тест URL напрямую:**
```bash
curl -I "http://api.maps.by/.../tile/9/163/291.pbf?token=YOUR_TOKEN"
```

Ожидается: `HTTP/1.1 200 OK`

#### Проблема: "VectorGrid library not loaded"

**Причина:** Нет интернета при загрузке библиотеки

**Решение:**
1. Проверьте подключение к интернету
2. Перезагрузите страницу карты (Ctrl+R в окне браузера)
3. Если проблема сохраняется — проверьте доступность unpkg.com

### 3. Проверка настроек

Откройте **Настройки** → **Карта** и убедитесь:

- ✅ Выбран тип **"Векторные тайлы (.pbf)"**
- ✅ URL содержит `.pbf` в конце
- ✅ URL содержит плейсхолдеры `{z}`, `{x}`, `{y}` (или `{z}`, `{y}`, `{x}`)
- ✅ Токен присутствует в query-string (`?token=...` или `&token=...`)
- ✅ Нет дублирования `token=` (только один раз)

**Пример правильного URL:**
```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=XXXXXX
```

⚠️ Обратите внимание: порядок `{z}/{y}/{x}`, а не `{z}/{x}/{y}`

### 4. Предупреждения при сохранении

Если при сохранении настроек появляется предупреждение:

```
⚠️ В URL обнаружены подозрительные символы: пробелы, символ '*'.
```

**Действия:**
1. Скопируйте токен заново с сайта провайдера
2. Вставьте в Блокнот и проверьте:
   - Нет лишних пробелов
   - Нет символов `*` между токенами
   - Токен один, не склеенный
3. Скопируйте очищенный токен в URL
4. Сохраните настройки

## Детальная диагностика

### Шаг 1: Откройте Network в DevTools

1. Откройте карту **"⬡ В браузере"**
2. Нажмите **F12** → вкладка **Network**
3. Перезагрузите страницу (Ctrl+R)
4. Найдите запросы с `.pbf` в конце

### Шаг 2: Проверьте статус запроса

Кликните на запрос `.pbf` и посмотрите:

| Статус | Причина | Решение |
|--------|---------|---------|
| **200 OK** | Всё хорошо, тайл загружен | Если карта пуста — проблема в рендеринге (см. ниже) |
| **401 Unauthorized** | Неверный токен | Получить новый токен |
| **403 Forbidden** | Нет прав доступа | Проверить подписку/план на сайте провайдера |
| **404 Not Found** | Неверный URL или координаты | Проверить порядок {x}/{y} vs {y}/{x} |
| **CORS error** | Браузер блокирует | Активировать прокси (см. выше) |
| **Timeout** | Сервер не отвечает | Проверить интернет, попробовать позже |

### Шаг 3: Проверьте тип контента

На вкладке **Headers** найдите:
```
Content-Type: application/x-protobuf
```

Если тип другой (`text/html`, `application/json`) — сервер отдаёт не тайл, а ошибку.

Перейдите на вкладку **Response** и прочитайте текст ошибки.

## Проблемы с Esri ArcGIS (api.maps.by и подобные)

Если URL содержит `VectorTileServer`:

```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/...
```

Это **Esri ArcGIS REST API**, а не стандартный Mapbox Vector Tiles.

**Известное ограничение:**
- `Leaflet.VectorGrid` может не полностью поддерживать Esri-формат
- Имена слоёв отличаются от Mapbox
- Может потребоваться другой рендерер (MapLibre GL JS)

**Проверка совместимости:**
1. Откройте консоль (F12)
2. Ищите сообщения `[VectorGrid] Tile loaded`
3. Если тайлы загружаются (статус 200), но карта пуста — формат несовместим

**Решение:**
- Использовать растровые тайлы от того же провайдера (если доступны)
- Или дождаться поддержки MapLibre GL JS в приложении (планируется)

## Контакты для поддержки

Если проблема не решилась:

1. Сделайте скриншот консоли (F12 → Console)
2. Сделайте скриншот Network (F12 → Network, вкладка с `.pbf`)
3. Скопируйте URL из настроек (без токена, замените на `***`)
4. Создайте issue на GitHub с описанием проблемы

**Шаблон сообщения:**
```
Векторные тайлы не загружаются

Провайдер: api.maps.by (или другой)
URL (без токена): http://api.maps.by/.../tile/{z}/{y}/{x}.pbf?token=***

Логи консоли:
[вставить скриншот или текст]

Network статус:
[вставить скриншот]
```

## Fallback на OSM

Если векторные тайлы не работают, приложение автоматически откатывается на OpenStreetMap (растровые тайлы).

Вы увидите уведомление:
```
⚠️ Не удалось загрузить векторные тайлы. Используется OpenStreetMap.
```

Это нормальное поведение — карта всегда будет доступна, даже если настроенная подложка не работает.

**Чтобы вернуть векторные тайлы:**
1. Исправьте проблему (см. выше)
2. Перезагрузите страницу карты (Ctrl+R в браузере или закройте/откройте карту в приложении)
