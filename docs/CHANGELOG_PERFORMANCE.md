  - Один воркер в пуле
  - Загружает собственный экземпляр Detector
  - Обрабатывает кадры независимо
  - Сигналы: frame_processed, sign_detected, error
- Класс `DetectorPool(QObject)`:
  - Управляет пулом воркеров
  - Автоопределение количества: `cpu_count // 2` (2-4)
  - Создаёт shared SignHandler с lock
  - Запускает AggregatorThread для обработки результатов
  - Методы: start(), stop(), get_result_signs(), get_turn_data()
- Класс `AggregatorThread`:
  - Забирает результаты из result_queue
  - Конвертирует в DetectedSign
  - Вызывает SignHandler (thread-safe через lock)
  - Обновляет UI (frame_ready, stats)

### 📝 Технические детали

**Алгоритм кэширования:**

1. Вычислить хэш crop'а 32x32 (xxHash или MD5)
2. Ключ кэша = `{yolo_class}:{hash}`
3. Проверить OrderedDict (O(1) lookup)
4. HIT → вернуть результат, переместить в конец (обновить LRU)
5. MISS → запустить CNN, сохранить результат, вытеснить старый если переполнение

**Структура кэша:**

```python
CNNCache._cache = OrderedDict([
    ("treugolnik:a3f2c8d9", ("1.21", 0.85)),
    ("krugH:9c8e7d6f", ("3.24", 0.92)),
    ("sub_1.21:a3f2c8d9", ("1.21", 0.88)),
    ...
])
```

**Почему OrderedDict?**
- Сохраняет порядок вставки
- O(1) доступ по ключу
- O(1) перемещение в конец (move_to_end)
- O(1) удаление первого (popitem)
