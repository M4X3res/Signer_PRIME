# Безопасность обновления перед релизом

Если Signer не завершился за время ожидания, Updater завершается с ошибкой до
замены файлов. Ошибки проверки процесса также не разрешают установку.

Крестик, Esc и кнопка отмены в окне загрузки запрашивают отмену. Окно остаётся
открытым до завершения рабочего потока. Поздний сигнал успешной загрузки после
отмены не запускает установку. Применение успешной загрузки также ждёт окончания потока.

Полное обновление удаляет только файлы из состава предыдущего релиза, которых
нет в новом. Пользовательские файлы вне этого списка сохраняются. Если удаляемый
файл изменён локально, обновление останавливается до изменений.

`build_delta.py` добавляет в манифест списки файлов предыдущих релизов из
`release_baselines/<version>`. Сохраняйте эти исходные сборки при подготовке релизов:
для старых установок без собственного манифеста они нужны и полному обновлению.
Если исходная сборка неизвестна, обновление отказывается угадывать, какие файлы удалять.

После успешного полного или дельта-обновления установщик сохраняет `manifest.json`
рядом с программой. Этот список обновляется в общей операции отката вместе с
файлами программы. Проверка ошибки установки возвращает прежние файлы и манифест.

Проверки: `tests.test_update_transaction`; Qt-сценарии запускаются отдельно через
`tests.test_update_dialog_lifecycle`, поскольку требуют QApplication.
Перед публикацией нужен отдельный прогон собранных Signer.exe и Updater.exe.
