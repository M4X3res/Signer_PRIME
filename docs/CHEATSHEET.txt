┌────────────────────────────────────────────────────────────────────────────┐
│ 📝 ОБНОВЛЕНИЕ ВЕРСИИ                                                       │
└────────────────────────────────────────────────────────────────────────────┘

  1. Открыть: version.json
  2. Изменить: "version": "2.0.X"
  3. Обновить: "build_date": "2026-XX-XX"


┌────────────────────────────────────────────────────────────────────────────┐
│ ⚡ БЫСТРАЯ ТЕСТОВАЯ СБОРКА                                                 │
└────────────────────────────────────────────────────────────────────────────┘

  Команда:    build_test.bat
  Время:      ~1-2 минуты
  Результат:  dist\Signer\Signer.exe
  
  Использовать для:
  • Проверка изменений
  • Локальное тестирование
  • Быстрая отладка


┌────────────────────────────────────────────────────────────────────────────┐
│ 📦 ПОЛНАЯ СБОРКА РЕЛИЗА                                                    │
└────────────────────────────────────────────────────────────────────────────┘

  Команда:    build_release.bat
  Время:      ~3-5 минут
  Результат:  release\ (архив + чексуммы)
  
  Создает:
  • Signer.7z.001, .002, .003, ... (100MB части)
  • checksum.sha256
  • release_notes.txt
  • README.md, BUILD_AUTOUPDATE.md


┌────────────────────────────────────────────────────────────────────────────┐
│ 🌐 ЗАГРУЗКА НА GITHUB                                                      │
└────────────────────────────────────────────────────────────────────────────┘

  Автоматически:
    powershell -ExecutionPolicy Bypass -File upload_release.ps1
    
  Опции:
    -Draft          Создать как черновик
    -PreRelease     Создать как пре-релиз
    -Version "X.X"  Указать версию вручную
  
  Вручную:
    1. https://github.com/YOUR_REPO/releases/new
    2. Тег: v2.0.X
    3. Загрузить ВСЕ файлы из release\
    4. Publish release


┌────────────────────────────────────────────────────────────────────────────┐
│ ⚙️ ТРЕБОВАНИЯ (первый раз)                                                 │
└────────────────────────────────────────────────────────────────────────────┘

  □ Python:       python --version
  □ PyInstaller:  pip install pyinstaller
  □ 7-Zip:        скопировать 7z.exe, 7z.dll → installer\
  □ GitHub CLI:   winget install --id GitHub.cli (для автозагрузки)
                  gh auth login


┌────────────────────────────────────────────────────────────────────────────┐
│ 🔧 БЫСТРОЕ ИСПРАВЛЕНИЕ ПРОБЛЕМ                                             │
└────────────────────────────────────────────────────────────────────────────┘

  PyInstaller ошибка:
    rmdir /s /q build dist
    build_test.bat
  
  7-Zip не найден:
    copy "C:\Program Files\7-Zip\7z.*" installer\
  
  GitHub CLI не авторизован:
    gh auth login
  
  Старые файлы мешают:
    rmdir /s /q release
