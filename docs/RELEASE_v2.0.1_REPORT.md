# Отчёт о подготовке релиза v2.0.1

## Дата: 2026-09-15

## Задача
Подготовить и зафиксировать релиз **v2.0.1** с гарантированной поддержкой CPU-бэкендов ONNX Runtime и OpenVINO в собранном приложении.

## Выполненные изменения

### 1. Версия (✅)
- **Файл:** `version.json`
- **Изменение:** Обновлена версия с `2.0.0` на `2.0.1`, актуализирована дата сборки `2026-09-15`

### 2. Зависимости (✅)
- **Файл:** `requirements.txt`
- **Изменение:** Добавлены обязательные CPU-бэкенды:
  ```
  # ── CPU Inference Backends (ОБЯЗАТЕЛЬНО для релиза v2.0.1+) ───────
  onnx>=1.22.0
  onnxruntime>=1.29.0  # CPU-only (НЕ onnxruntime-gpu!)
  openvino>=2024.0
  ```
- **Примечание:** `requirements-cpu-backends.txt` сохранён как справочный файл

### 3. Скрипт экспорта моделей (✅)
- **Файл:** `scripts/export_models_onnx.py` (перемещён из `scripts/archive/`)
- **Изменения:**
  - Добавлена поддержка `--format all` для экспорта в оба формата сразу
  - Улучшено логирование прогресса
  - Добавлена проверка версий зависимостей
  - Возвращает код ошибки 1 при неудачном экспорте

### 4. Скрипт верификации CPU-бэкендов (✅)
- **Файл:** `scripts/build/verify_cpu_backends.py` (новый)
- **Функциональность:**
  - Временно переключает `cpu_inference_backend` на `"onnx"` и `"openvino"`
  - Вызывает `configs.sign_models.verify_backend_active()`
  - Проверяет, что все модели загружаются с правильным backend
  - Выводит таблицу результатов: `model_name → actual_backend`
  - Возвращает код ошибки 1, если хотя бы одна модель откатилась на PyTorch
- **TODO:** Реализовать проверку через собранный .exe (сейчас работает только в dev-режиме)

### 5. Обновление prepare_release.bat (✅)
- **Файл:** `scripts/build/prepare_release.bat`
- **Изменения:**
  - Обновлена нумерация шагов с 7 на 9
  - **[3/9] Новый шаг:** Экспорт моделей в ONNX и OpenVINO
    - Вызывает `scripts/export_models_onnx.py --format all`
    - Прерывает сборку при ошибке экспорта с понятным сообщением
  - **[6/9] Новый шаг:** Верификация CPU-бэкендов
    - Вызывает `scripts/build/verify_cpu_backends.py`
    - Прерывает сборку при ошибке верификации с понятным сообщением
  - Обновлены release notes по умолчанию с упоминанием CPU-бэкендов

### 6. Улучшения signer.spec (✅)
- **Файл:** `signer.spec`
- **Изменения:**
  - **Явная проверка пакетов:** Добавлена функция `check_package_installed()` для проверки наличия `onnxruntime` и `openvino` в venv сборки
  - **Прерывание сборки:** При отсутствии пакетов вызывается `RuntimeError` с понятным сообщением
  - **Проверка экспортированных моделей:**
    - Используется `glob.glob()` для поиска `.onnx` и `*_openvino_model/` файлов
    - Если модели не найдены — `RuntimeError` с инструкцией по экспорту
  - **Улучшенное логирование:**
    - Выводится количество найденных библиотек для каждого бэкенда
    - Выводится количество найденных экспортированных моделей
    - Выводится количество найденных submodules

## Следующие шаги

1. **Установить зависимости:**
   ```bash
   pip install onnx onnxruntime openvino openvino-dev
   ```

2. **Запустить тесты:**
   ```bash
   pytest tests/test_model_export.py -v
   pytest tests/test_onnx_backend.py -v
   ```

3. **Запустить экспорт моделей:**
   ```bash
   python scripts/export_models_onnx.py --format all
   ```

4. **Запустить верификацию:**
   ```bash
   python scripts/build/verify_cpu_backends.py
   ```

5. **Запустить полную сборку:**
   ```bash
   scripts\build\prepare_release.bat
   ```

6. **Проверить релиз:**
   - Распаковать архив из `release/`
   - Запустить `Signer.exe`
   - Открыть Settings → Performance
   - Переключить CPU inference backend между ONNX Runtime, OpenVINO, PyTorch
   - Запустить обработку видео и убедиться, что бэкенды работают

7. **Опубликовать релиз:**
   ```powershell
   .\scripts\build\upload_release.ps1
   ```
