## Корневая причина бага

**Проблема:** Пользователь вставил URL **конкретного тайла** вместо **шаблона с плейсхолдерами**.

### Пример неправильного URL (из бага):
```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/9/163/291.pbf?token=...
                                                               ^^^^^^^^
                                                               Конкретные координаты!
```

### Пример правильного URL (с плейсхолдерами):
```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=...&
                                                               ^^^^^^^^^^            ^
                                                               Плейсхолдеры!         Оборванный URL
```

### Механизм бага:

1. **Leaflet** запрашивает разные тайлы: (9,163,291), (9,164,291), (9,163,292)...
2. **Сервер** (из-за отсутствия плейсхолдеров) каждый раз возвращает **один и тот же тайл** 9/163/291
3. **Результат:** Один и тот же PBF-тайл отрисовывается во всех ячейках сетки
4. **Визуально:** Мозаика из одинаковых повторяющихся синих фигур вместо карты

### ✅ 2. Defensive проверка на бэкенде (`server/map_server.py`)

**Обновлена функция `_build_upstream_tile_url()`:**

```python
def _build_upstream_tile_url(template: str, z: int, x: int, y: int) -> str:
    """
    КОРНЕВАЯ ПРИЧИНА БАГА "мозаичной" карты: Если template не содержит 
    плейсхолдеров {z}/{x}/{y}, подстановка не происходит, и мы каждый раз 
    запрашиваем ОДИН И ТОТ ЖЕ тайл независимо от координат.
    """
    original_template = template
    
    url = (
        template
        .replace("{z}", str(z))
        .replace("{x}", str(x))
        .replace("{y}", str(y))
        .replace("{s}", "a")
    )
    
    # DEFENSIVE CHECK: Подстановка должна была изменить URL
    if url == original_template:
        raise ValueError(
            f"Vector tile template does not contain placeholders {{z}}/{{x}}/{{y}}. "
            f"Template appears to be a URL of a single specific tile, not a template. "
            f"All tile requests will return the same tile, resulting in a 'mosaic' pattern."
        )
    
    return url
```
