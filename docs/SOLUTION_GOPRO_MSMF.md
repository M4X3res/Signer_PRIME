# РЕШЕНИЕ: GoPro видео падает на 44 кадре

## Проблема
При обработке GoPro видео через OpenCV происходит сбой на 44-м кадре:
```
packet read max attempts exceeded, if your video have multiple streams
OPENCV_FFMPEG_READ_ATTEMPTS (current value is 16000)
```

## Корневая причина

**GoPro MP4 файлы содержат множественные потоки:**
- Видео поток
- Аудио поток  
- GPS поток (метаданные геолокации)
- Акселерометр поток (данные ориентации)

**FFMPEG бэкенд OpenCV:**
- Не справляется с синхронизацией множественных потоков
- Падает после ~44 кадров
- Переменная `OPENCV_FFMPEG_READ_ATTEMPTS` НЕ применяется из Python кода

## Решение

### ✅ Используем MSMF бэкенд (Windows Media Foundation)

```python
cap = cv2.VideoCapture(video_path, cv2.CAP_MSMF)
```

**Преимущества MSMF:**
- Нативная поддержка Windows
- Корректно обрабатывает множественные потоки MP4
- Надежное чтение GoPro файлов
- Не требует дополнительных настроек

## Сравнение бэкендов

| Бэкенд | Результат | Примечание |
|--------|-----------|------------|
| **FFMPEG** | ❌ Падает на 44 кадре | Проблема с множественными потоками |
| **MSMF** | ✅ Работает корректно | Рекомендуется для GoPro на Windows |
| **DSHOW** | ❌ Не открывается | Устаревший бэкенд |

## Изменения в коде

### processing/video_reader.py

```python
# Было (FFMPEG - не работает):
cap = cv2.VideoCapture(video_path, cv2.CAP_FFMPEG)

# Стало (MSMF - работает):
cap = cv2.VideoCapture(video_path, cv2.CAP_MSMF)
if not cap.isOpened():
    cap = cv2.VideoCapture(video_path)  # Fallback
```

## Почему старый проект работал?

Возможные причины:
1. **Версия OpenCV** - разные версии могут использовать разные бэкенды по умолчанию
2. **Порядок компиляции** - в старой установке MSMF мог быть приоритетным
3. **Системные библиотеки** - разная конфигурация FFMPEG на системе

## Альтернативные решения (если MSMF не доступен)

### 1. Переупаковка видео без GPS/акселерометра:
```bash
ffmpeg -i input.mp4 -map 0:v:0 -map 0:a:0 -c copy output.mp4
```

### 2. Установка системной переменной (может не сработать):
```cmd
setx OPENCV_FFMPEG_READ_ATTEMPTS "100000"
```
Требует перезапуск системы.

### 3. Использование другой библиотеки для чтения:
- `imageio-ffmpeg`
- `decord`
- `PyAV`

## Платформы

**Linux/Mac:** Используйте переупаковку видео или альтернативные библиотеки
