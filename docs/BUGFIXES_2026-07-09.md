# Исправления багов — 2026-07-09

## Проблемы

1. **Кнопка "Завершить" не сохраняет знаки** — знаки терялись при использовании DetectorPool
2. **Медленная работа** — параллельные детекторы не протестированы, могут вызывать проблемы

## Исправления

### 1. DetectorPool — не сохранял знаки

**Проблема:**
```python
# В detector_pool.py
if self._sign_handler.result_signs:
    for sign in self._sign_handler.result_signs:
        pass  # Ничего не делали!
    self._sign_handler.result_signs.clear()  # И очищали!
```

**Результат:** При нажатии "Завершить" → `get_result_signs()` возвращал пустой список.

**Исправление:**
```python
# НЕ очищаем result_signs — они нужны для get_result_signs()
# Комментарий: Финализированные знаки НЕ ОЧИЩАЕМ!
```

**Файл:** `processing/detector_pool.py`, строка ~310

---

### 2. Параллельные детекторы отключены по умолчанию

**Причина:** Недостаточно протестированы, могут вызывать:
- Race conditions в SignHandler
- Проблемы с памятью (4-8 ГБ на модели)
- Непредсказуемую производительность

**Изменения:**

#### `processing/processing_controller.py`
```python
USE_DETECTOR_POOL = False  # ВРЕМЕННО ОТКЛЮЧЕНО
```

#### `ui/widgets/settings_page.py`
```python
self._parallel_toggle = ToggleButton(False)  # По умолчанию выключено

proc_group.add_row(
    "Параллельные детекторы (BETA)",  # Добавлена пометка BETA
    "Использовать пул из 2-4 детекторов (требует тестирования)",
    self._parallel_toggle,
)
```

#### `_reset()`
```python
self._parallel_toggle.set_checked(False)  # False вместо True
```

### 3. Checkpoint — исправлена работа с пулом

**Проблема:**
```python
if not self._detector:
    return  # Не работало с _detector_pool!
```

**Исправление:**
```python
# Получаем SignHandler (из детектора или пула)
if self._detector_pool and hasattr(self._detector_pool, '_sign_handler'):
    sign_handler = self._detector_pool._sign_handler
elif self._detector and hasattr(self._detector, '_sign_handler'):
    sign_handler = self._detector._sign_handler
else:
    return  # Нет данных
```

**Файл:** `processing/processing_controller.py`, метод `save_checkpoint()`
