# Исправление мозаичной карты: Краткое руководство

## Проблема: Одинаковые повторяющиеся фигуры вместо карты

### Причина
Вы вставили URL **конкретного тайла** вместо **шаблона**.

### Решение
Замените конкретные координаты на плейсхолдеры `{z}/{x}/{y}`.

---

## Быстрое исправление

### ❌ НЕПРАВИЛЬНО:
```
http://api.maps.by/.../tile/9/163/291.pbf?token=ABC
                           ^^^^^^^^
```

### ✅ ПРАВИЛЬНО:
```
http://api.maps.by/.../tile/{z}/{y}/{x}.pbf?token=ABC
                           ^^^^^^^^^^
```

---

## Приложение защитит вас

При попытке сохранить неправильный URL вы увидите:

```
❌ КРИТИЧЕСКАЯ ОШИБКА: URL не содержит {z}, {x}, {y}

Без плейсхолдеров карта будет мозаикой!

❌ Сохранение отменено.
```

**Исправьте URL и попробуйте снова.**

---

## Порядок координат

- **api.maps.by:** `{z}/{y}/{x}` ⚠️
- **Mapbox:** `{z}/{x}/{y}`
- **Сверьтесь с документацией провайдера!**
