# Частичные обновления

`scripts/build/prepare_release.bat` создаёт полный архив, `manifest.json` и дельты для сохранённых чистых сборок в `release_baselines/<version>/`. После сборки новая версия сохраняется там автоматически. Каталог содержит большие файлы и исключён из Git; его нужно сохранять на машине сборки.

Для ранее выпущенной версии можно поместить точное содержимое её дистрибутива (Signer.exe, version.json, _internal и остальные файлы) в `release_baselines/<version>/`. Не используйте рабочую установку с пользовательскими данными. Новая сборка той же версии с другим содержимым запрещена: увеличьте версию.

`scripts/build/upload_release.ps1` публикует полный архив, контрольные суммы, общий манифест и пары `delta-from-X.zip` / `delta-from-X.json`. Для каждой исходной версии свой манифест. Не изменяйте опубликованные файлы релиза на месте; выпускайте новую версию.

Клиент скачивает только дельту, соответствующую своей версии. При отсутствии подходящей дельты используется полный архив. Частичность означает целые изменённые файлы, не бинарные патчи: неизменившиеся веса моделей не попадают в дельту.

Установщик проверяет исходную версию, хэши исходных файлов, архив и результат установки. Локально изменённые файлы исходной сборки приводят к отказу от установки дельты, а не к молчаливому повреждению программы. В таком случае используйте полный дистрибутив. При обычной ошибке замены выполняется откат; если сам откат не удаётся, резервная копия сохраняется рядом с установкой, путь выводится в журнал.

Первое обновление со старого клиента будет полным: он не понимает новые отдельные манифесты дельт. После установки обновлённого клиента последующие релизы смогут загружаться частично.

Проверка: `.venv/Scripts/python.exe -m unittest tests.test_update_transaction -v`.

Перед публичным выпуском проверьте переход между двумя собранными Windows-дистрибутивами на отдельной установке. Модульные тесты не заменяют проверку PyInstaller, прав каталога установки и антивируса. Откат рассчитан на обработанные ошибки; восстановление после отключения питания во время замены файлов не реализовано.
