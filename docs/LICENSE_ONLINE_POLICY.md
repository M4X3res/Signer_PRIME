# Проверка лицензии

При запуске требуется успешная проверка на сервере лицензий. Сохранённый
подписанный токен сам по себе не разрешает запуск без интернета.

Периодического таймера нет. Проверка выполняется после запуска и возобновления
обработки, запуска сохранения результатов и его завершения, сохранения в редакторе,
экспорта GeoJSON и изменений карты. В интерфейсе запрос выполняется асинхронно.
Сервер карты проверяет лицензию после успешного выполнения соответствующего запроса.
Уже выполненная операция сохраняет свой результат, даже если проверка затем не прошла.

После отрицательного ответа или ошибки соединения дальнейшая работа блокируется.
Обработка перестаёт читать новые кадры, завершает принятую очередь и сохраняет
контрольную точку. После восстановления связи пользователь может повторить проверку.
Известная блокировка не позволяет выполнить очередное действие до восстановления доступа.

Потеря соединения обнаруживается только при следующем ключевом действии.
При простое и длительной обработке без новых действий сетевых проверок нет.
Подтверждение не истекает через пять минут; срок самой подписки учитывается
при проверке локального доступа.

Ответ сервера должен содержать корректно подписанный действующий токен.
Запись токена атомарная. Отзыв лицензии и деактивация устройства блокируют доступ,
даже после удаления локального токена. Поддерживаются ошибки API в поле detail FastAPI.

Перед публикацией необходимо сверить встроенный публичный ключ с рабочим сервером.
Проверка известного тестового ключа при сборке не подтверждает это соответствие.

Регрессионные проверки: tests.test_license_online. Используются временные ключи
и подставные ответы, без обращений к рабочему серверу.
