# Временное отключение Process Pool режима

~~**ОТМЕНЕНО — ИСПРАВЛЕНИЕ РЕАЛИЗОВАНО**~~

**Дата**: 2026-08-26 09:30  
**Статус**: ⛔ **ОТМЕНЕНО**

---

## История

Этот workaround был создан, когда первые попытки исправления краша 0xC0000409 не помогли. Process Pool был временно удалён из UI для защиты пользователей.

## Окончательное решение

Вместо отключения режима была реализована **агрессивная стратегия shutdown**:
- Принудительный terminate/kill worker процессов
- Отмена pending futures
- Graceful degradation при ошибках

**См. полное решение**: `BUGFIX_PROCESS_POOL_0xC0000409.md`
