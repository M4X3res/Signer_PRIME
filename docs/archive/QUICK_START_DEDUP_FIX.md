## Как проверить

### 1. Запустить тест (подтвердить что фикс работает)

```bash
.venv\Scripts\python.exe tests\test_attach_unmatched_fix.py
```

Ожидается:
```
[PASS] Test 1
[PASS] Test 2
[OK] All _attach_unmatched tests passed (2/2)
```

### 2. Включить диагностику (для анализа на реальных видео)

В файле `.kiro/settings/settings.json` добавить:
```json
{
  "verbose_log": true
}
```

Или через Settings UI: поставить галочку "Verbose Logging" (если есть в UI)

### 3. Обработать тестовое видео

Выбрать видео, где **раньше наблюдались дубликаты** одного знака на карте.

Запустить обработку.

### 4. Проверить результат

**A. Визуально** (основное):
- Открыть карту (`templates/map.html` через встроенный сервер)
- Проверить что дубликатов **меньше** чем раньше (или нет совсем)

**B. Логи** (для понимания причины):
- Открыть `roadscan.log`
- Искать строки с `missed_matches_due_to_gap` (если диагностика включена)
- Если там много значений в диапазоне 7-25 → проблема подтверждена, нужны **дополнительные фиксы**

## Что дальше?

### Если дубли всё ещё есть

Это **ожидаемо** — исправленный баг (Шаг 1) — это только **часть** решения.

Полное решение требует:
- **Часть 1, Шаги 2-3**: Сделать пороги трекинга адаптивными к реальному frame skip
  - Сейчас: жёсткие константы `gap < 7` и `DIFF_FRAMES_REMOVE = 5`
  - Проблема: реальный skip может достигать 25 кадров (5×5)
  - Требуется: привязать пороги к `config.FRAME_STEP × current_skip`
  - **Это большое изменение**, требует тестирования на разных видео

См. детали в `DEDUP_FIX_STATUS.md`

### Если дубли пропали или стали реже

✅ Отлично! Фикс Шага 1 оказался достаточным для вашего сценария.

Можно:
- Оставить как есть (если результат устраивает)
- Или всё равно сделать Шаги 2-3 для большей надёжности на других видео

## Важно

- **Не увеличивайте `dedup_radius_track_m` вслепую** — это маскирует симптом, а не лечит причину
- **Включайте `verbose_log` только для диагностики** — это добавляет overhead
- **Тестируйте на видео с разными скоростями** (город vs трасса — разные профили skip)
