## 🔍 Как проверить

### 1. Проверка точности классификации

**Шаги:**
1. Запустите приложение
2. Выберите GeoJSON файл на Dashboard
3. Перейдите на страницу "Редактор ошибок"
4. Нажмите "↑ Загрузить GeoJSON"

**Ожидаемый результат:**
- В списке знаков колонка "Уверенность" показывает **разные** значения
- Есть знаки с высокой уверенностью (>70%, зелёный)
- Есть знаки со средней уверенностью (40-70%, жёлтый)
- Есть знаки с низкой уверенностью (<40%, красный)

**Логи в консоли:**
```
[ErrorEditor] load_geojson вызван, target = ...
[ErrorEditor] Загружаем GeoJSON из ...
[ErrorEditor] Найдено N features в GeoJSON
[ErrorEditor] Создано N SignRecord объектов
```

## 🐛 Возможные проблемы

### Проблема: Точность всё ещё показывает ~50%

**Причина:** Используется старый GeoJSON без полей `conf_cnn`, `cnn_count`, `observation_count`

**Решение:**
1. Удалите старый GeoJSON
2. Запустите обработку заново
3. Новый GeoJSON будет содержать правильные поля

**Проверка:**
Откройте GeoJSON в текстовом редакторе и найдите в properties:
```json
"conf_cnn": "0.850",
"cnn_count": "17",
"observation_count": "20"
```

---

### Проблема: Знаки не появляются на карте

**Диагностика:**

1. **Проверьте логи сервера:**
   ```
   [API /api/signs] PATH_TO_GEOJSON пустой
   ```
   → **Решение:** Выберите GeoJSON на Dashboard

2. **Проверьте логи сервера:**
   ```
   [API /api/signs] Файл не найден: ...
   ```
   → **Решение:** Проверьте что файл существует по указанному пути

3. **Проверьте логи сервера:**
   ```
   [API /api/signs] Найдено 0 features в GeoJSON
   ```
   → **Решение:** GeoJSON пустой, запустите обработку

4. **Проверьте логи сервера:**
   ```
   [API /api/signs] Некорректный формат координат для ...
   [API /api/signs] Невалидные координаты для ...
   ```
   → **Решение:** Проблема с данными GPS, проверьте GPX файл

5. **Проверьте браузерную консоль (F12):**
   ```
   [loadSigns] Signs API returned 404
   ```
   → **Решение:** Сервер не запущен, перезапустите приложение

---

### Проблема: Трек не отображается

**Диагностика:**

1. **Проверьте логи сервера:**
   ```
   [API /api/track] PATH_TO_GPX пустой
   ```
   → **Решение:** Выберите GPX на Dashboard

2. **Проверьте логи сервера:**
   ```
   [API /api/track] Файл не найден: ...
   ```
   → **Решение:** Проверьте что файл существует

3. **Проверьте логи сервера:**
   ```
   [API /api/track] Найдено 0 точек трека
   ```
   → **Решение:** GPX файл пустой или некорректный

## 🧪 Тест в браузере

Откройте браузер и проверьте API напрямую:

### Тест 1: Проверка знаков
```
http://localhost:3000/api/signs
```

```json
[
  {
    "id": "uuid",
    "type": "3.24",
    "lat": 53.902345,
    "lon": 27.561234,
    "line": [[27.561234, 53.902345], [27.561456, 53.902567]]
  }
]
```

```
http://localhost:3000/api/track
```

```json
[
  [53.902345, 27.561234],

]
```

## 📝 Примечания

1. **После обновления кода** — перезапустите приложение
2. **После загрузки нового GeoJSON** — нажмите "↺ Перезагрузить" на странице карты
3. **Для старых GeoJSON** — рекомендуется перезапустить обработку
4. **Все логи** выводятся в консоль приложения (не в браузер)
