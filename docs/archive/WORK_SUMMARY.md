### ✅ Часть 2: Конвейер уверенности — РЕАЛИЗОВАН ПОЛНОСТЬЮ

**Проблема:** Метод `calc_confidence()` существовал, но **нигде не вызывался** (мертвый код). GeoJSON содержал поля уверенности, но они не заполнялись реальными данными.

**Решение:**

1. **core/osm_snap.py:**
   - Добавлено поле `distance_m: float` в `SnapResult`
   - `_find_closest_segment()` теперь возвращает расстояние до дороги
   - `OSMSnapper.snap()` передает `distance_m` в результат

2. **core/final_handler.py:**
   - `_snap_sign_coords()` сохраняет GPX азимут перед snap
   - Вызывает `sign.calc_confidence()` с параметрами:
     - `snap_dist_m` — расстояние до дороги
     - `osm_azimuth` — азимут дороги из OSM
     - `gpx_azimuth` — оригинальный азимут из GPS трека
   - Обрабатывает случаи успешного и неуспешного snap

3. **ui/widgets/error_editor_page.py:**
   - Фильтр `_apply_filter()` использует `total_confidence` вместо `confidence`
   - UI уже отображал обе уверенности раздельно (CNN и GPS)

4. **tests/test_confidence.py:**
   - Создано 12 тестов для проверки всех сценариев:
     - Идеальный/плохой/средний snap
     - Короткие/длинные треки
     - Wraparound азимутов (359° vs 1°)
     - Нулевые наблюдения

**Метрики уверенности:**

- **conf_cnn**: стабильность классификации CNN (`cnn_count / observation_count`)
- **conf_placement**: качество постановки (взвешенная из 4 факторов):
  - Стабильность трека (разброс `pixel_x`)
  - Длина трека (количество наблюдений)
  - OSM snap качество (расстояние 0-30м)
  - Расхождение азимутов GPX vs OSM (0-45°)
- **conf_total**: `0.5 * conf_cnn + 0.5 * conf_placement`
