# Исправление двойного срабатывания кнопки "Завершить"

## Дата: 2026-07-10

### Проблема
Кнопка "Завершить" срабатывала со второго раза или требовала двойного клика для корректной работы.

### Причина
1. **Отсутствие защиты от двойного клика** — кнопка была напрямую подключена к сигналу без debounce
2. **Отсутствие визуальной обратной связи** — пользователь не видел что кнопка уже нажата
3. **Отсутствие блокировки кнопки** — кнопка оставалась активной после первого клика

### Решение

#### 1. ProcessingPage (ui/widgets/processing_page.py)

**Добавлен флаг защиты:**
```python
def __init__(self):
    self._finish_clicked = False  # Защита от двойного клика
```

**Добавлен обработчик с защитой:**
```python
def _on_finish_clicked(self):
    # Защита от повторного нажатия
    if self._finish_clicked:
        return
    
    self._finish_clicked = True
    
    # Немедленно отключаем обе кнопки
    self.btn_finish.setEnabled(False)
    self.btn_pause.setEnabled(False)
    
    # Визуальная обратная связь
    self.btn_finish.setText("⏳  Завершение…")
    
    # Отправляем сигнал
    self.finish_requested.emit()
```

**Сброс флага при новой обработке:**
```python
def set_active(self, active: bool):
    if not active:
        self._finish_clicked = False  # Сброс для новой обработки
```

#### 2. MainWindow (ui/main_window.py)

**Добавлена защита в _on_finish_requested:**
```python
def _on_finish_requested(self):
    # Защита от повторного вызова
    if hasattr(self, '_finish_requested_called') and self._finish_requested_called:
        print("[MainWindow] _on_finish_requested уже был вызван, игнорируем")
        return
    
    self._finish_requested_called = True
    # ... остальной код
```

**Сброс флагов при старте:**
```python
def _on_start(self):
    # Сбрасываем флаги при старте новой обработки
    self._finish_requested_called = False
    self._finish_called = False
    # ...
```

**Сброс после завершения:**
```python
def _on_finish(self):
    # ... сохранение данных
    
    # Сбрасываем флаги для следующей обработки
    self._finish_called = False
    self._finish_requested_called = False
```

### Поведение после исправления

1. **Первый клик:**
   - Кнопка немедленно блокируется
   - Текст меняется на "⏳  Завершение…"
   - Отключается кнопка "Пауза"
   - Отправляется сигнал `finish_requested`

2. **Попытка повторного клика:**
   - Полностью игнорируется (кнопка disabled)
   - Если пользователь как-то обходит disabled — флаг `_finish_clicked` блокирует повторную обработку

3. **Защита на уровне MainWindow:**
   - Даже если сигнал пришёл дважды — флаг `_finish_requested_called` блокирует повторный вызов контроллера

4. **Новая обработка:**
   - При старте новой обработки все флаги сбрасываются
   - Кнопка снова становится активной
   - Текст возвращается к "■   Завершить"

### Технические детали

**Уровни защиты:**

1. **UI уровень** (processing_page.py):
   - `self._finish_clicked` — флаг на уровне виджета
   - `btn_finish.setEnabled(False)` — блокировка кнопки
   - Визуальная обратная связь

2. **Signal handler уровень** (main_window.py):
   - `self._finish_requested_called` — флаг на уровне обработчика
   - Логирование повторных вызовов
   - Блокировка до сброса флага

3. **Controller уровень** (processing_controller.py):
   - Существующая логика `finish_and_save()` с ожиданием завершения потоков
   - Timeout защита (5 сек reader, 10 сек detector)

**Жизненный цикл флагов:**

```
Старт обработки:
  _finish_clicked = False
  _finish_requested_called = False
  btn_finish.enabled = True

Клик "Завершить":
  _finish_clicked = True          ← блокировка в UI
  _finish_requested_called = True ← блокировка в handler
  btn_finish.enabled = False
  btn_finish.text = "⏳  Завершение…"

Завершение обработки:
  _finish_called = True (в _on_finish)
  ... сохранение данных ...
  _finish_called = False          ← сброс
  _finish_requested_called = False ← сброс

set_active(False):
  _finish_clicked = False          ← сброс в UI
  btn_finish.enabled = False

Новая обработка:
  _finish_clicked = False          ← явный сброс
  _finish_requested_called = False ← явный сброс
  btn_finish.enabled = True
  btn_finish.text = "■   Завершить"
```

### Обратная совместимость

Все изменения внутренние, API не меняется:
- Сигнал `finish_requested` работает как раньше
- Метод `set_active()` работает как раньше
- Добавлена только дополнительная защита

### Логирование

Добавлено логирование для отладки:

Позволяет отслеживать попытки двойных кликов в консоли.
