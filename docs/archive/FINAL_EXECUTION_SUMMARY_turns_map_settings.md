**Файлы изменены:**
- `core/sign_handler.py:382-395`

**Код:**
```python
# BLOCK 1.3: вызываем handle_turn() только если bearing-геометрия отключена
from configs.settings import get_app_settings
settings = get_app_settings()

    turn.handle_turn()
```

**Эффект:**
- **До:** O(кадры × точки_трека) парсингов GPX + эвристика на каждом повороте
- **После:** O(1) парсинг GPX + эвристика только при `turn_use_bearing_geometry=False`
- **Ускорение:** Кратное (порядок величины) на длинных треках с множеством знаков

**Критерии приёмки:**
- ✅ GPXHandler создаётся 1 раз за обработку видео
- ✅ Эвристика пропускается в дефолтном режиме
- ✅ Поведение идентично (чистый перформанс-фикс)
- ⚠️ Замеры через profiler.py не проводились (нет тестового ролика)
