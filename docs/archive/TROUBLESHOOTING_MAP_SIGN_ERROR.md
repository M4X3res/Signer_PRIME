# Диагностика ошибки "Ошибка загрузки знака" при клике на карте

## Проблема
При клике на маркер знака на карте появляется сообщение "Ошибка загрузки знака".

## Причины и решения

### 1. GeoJSON файл не существует или пуст

**Проверка:**
```bash
# Проверьте что файл существует
ls -l output/result.geojson

# Проверьте что файл не пустой
cat output/result.geojson | head -20
```

**Решение:**
- Запустите обработку видео и дождитесь её завершения
- Убедитесь что в output/result.geojson есть features

### 2. Некорректный формат ID знаков

**Диагностика:**
1. Откройте консоль браузера (F12)
2. Кликните на знак на карте
3. Посмотрите логи в консоли:
   ```
   [selectSign] Начало загрузки знака, id: <значение>
   [selectSign] Запрос к: http://127.0.0.1:3000/api/sign/<id>
   [selectSign] Ответ получен, status: <код>
   ```

**Возможные проблемы:**
- **404 Not Found**: знак с таким ID не найден в GeoJSON
  - Проверьте что ID в маркере совпадает с ID в файле
  - Пересоздайте GeoJSON через повторную обработку
  
- **500 Server Error**: ошибка на сервере
  - Проверьте консоль Python приложения
  - Посмотрите полный traceback ошибки

### 3. Проблемы с сервером Flask

**Проверка:**
```bash
# В консоли приложения должны быть логи:
[API /api/sign/<id>] Запрос получен
[API /api/sign/<id>] Найдено N features в GeoJSON
[API /api/sign/<id>] Знак найден
```

**Если логов нет:**
- Сервер Flask не запущен или не отвечает
- Проверьте что карта открылась через встроенный сервер (порт 3000)

### 4. CORS или network ошибки

**Диагностика в консоли браузера:**
```javascript
// Должен быть успешный запрос
fetch('http://127.0.0.1:3000/api/sign/<id>')
  .then(r => r.json())
  .then(console.log)
```

**Решение:**
- Перезапустите приложение
- Убедитесь что используется 127.0.0.1, а не localhost

## Расширенная диагностика

### Проверка структуры GeoJSON

Откройте `output/result.geojson` и проверьте что features содержат:
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "id": "уникальный-id",  ← Это поле обязательно!
        "type": "3.24",
        "code": "324",
        "time": "00:01:23",
        ...
      },
      "geometry": {
        "type": "LineString",
        "coordinates": [[lon, lat], ...]
      }
    }
  ]
}
```

### Проверка логов сервера

В консоли приложения при клике на знак должны появиться логи:
```
[API /api/sign/abc123] Запрос получен
[API /api/sign/abc123] Найдено 150 features в GeoJSON
[API /api/sign/abc123] Знак найден
```

Если видите "Знак не найден", значит ID не совпадает.

### Проверка логов браузера

Откройте DevTools (F12) → Console и посмотрите детальные логи:
```
[selectSign] Начало загрузки знака, id: abc123
[selectSign] Запрос к: http://127.0.0.1:3000/api/sign/abc123
[selectSign] Ответ получен, status: 200
[selectSign] Данные знака получены: {type: "Feature", properties: {...}}
[selectSign] Properties: {id: "abc123", type: "3.24", ...}
[selectSign] Знак успешно загружен
```

## Быстрое решение

1. Закройте приложение
2. Удалите `output/result.geojson`
3. Запустите приложение заново
4. Выполните обработку видео
5. Дождитесь завершения (появится "Обработка завершена")
6. Перейдите на вкладку "Карта"
7. Кликните на любой маркер знака

Если проблема сохраняется:
- Откройте консоль браузера (F12)
- Сделайте скриншот логов
- Проверьте консоль Python приложения на наличие ошибок
