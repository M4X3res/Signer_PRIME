# ✅ Карта исправлена

## Проблема
Карта не загружалась из-за множественных синтаксических ошибок в JavaScript, связанных с Unicode-символами и экранированием кавычек.

## Исправления

### 1. Функция openVideoWindow()
**Было:**
- Template literal с вложенным HTML и JavaScript
- Unicode символы (⏸, ▶, «, ») в строках
- Конфликт кавычек

**Стало:**
- `document.write()` для построения HTML
- Простые ASCII символы вместо Unicode
- Правильное экранирование `<\/script>`

### 2. Кнопки управления видео
**Было:**
```html
<button>⛶</button>  <!-- Полноэкранный режим -->
<button>⧉</button>  <!-- Отдельное окно -->
<button>« 10с</button>  <!-- Назад -->
<button>⏸ Пауза</button>  <!-- Пауза -->
```

**Стало:**
```html
<button>[ ]</button>  <!-- Полноэкранный режим -->
<button>+</button>    <!-- Отдельное окно -->
<button>-10s</button> <!-- Назад -->
<button>Pause</button> <!-- Пауза -->
```

## Использование

1. **Перезапустить приложение:**
   ```bash
   taskkill /F /IM python.exe
   python main.py
   ```

2. **Открыть карту**

3. **Кликнуть на знак** → видео загрузится

4. **Управление:**
   - Кнопки скорости: 0.25x, 0.5x, 1x, 2x, 5x, 10x
   - `[ ]` — полноэкранный режим
   - `+` — открыть в отдельном окне

5. **В отдельном окне:**
   - Кнопки скорости
   - `-10s`, `-1s`, `+1s`, `+10s` — перемотка
   - `Play`/`Pause` — управление воспроизведением
   - **Горячие клавиши:**
     - `Space` — пауза/воспроизведение
     - `←` → — перемотка ±5 сек
     - `↑` ↓ — громкость ±10%
     - `F` — полноэкранный режим
