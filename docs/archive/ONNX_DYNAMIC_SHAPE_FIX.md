# Исправление размера входа ONNX моделей (Dynamic Shape)

## Проблема

После переключения на ONNX модели возникала ошибка:

```
Error in execution: Got invalid dimensions for input: images
index: 2 Got: 608 Expected: 960
index: 3 Got: 608 Expected: 960
```

**Причина**: ONNX модели были экспортированы с фиксированным размером входа `960x960`, но код детектора использует `imgsz=608`.

## Решение

### 1. Исправлен `scripts/export_models_onnx.py`

Изменён экспорт для использования `dynamic=True` для **всех** типов моделей (не только classify):

**Было:**
```python
# Для классификационных моделей обязательно dynamic=True
dynamic = (task == "classify")
result = model.export(
    format="onnx",
    dynamic=dynamic,
    simplify=True,
    opset=12
)
```

**Стало:**
```python
# BLOCK M: Для всех типов моделей используем dynamic=True
# Это позволяет использовать разные размеры входа (608, 640, 960 и т.д.)
result = model.export(
    format="onnx",
    dynamic=True,  # Всегда True для гибкости
    simplify=True,
    opset=12
)
```

Аналогично для OpenVINO:
```python
# BLOCK M: OpenVINO тоже с dynamic=True для гибкости размера входа
result = model.export(
    format="openvino",
    dynamic=True
)
```

### 2. Переэкспортированы все модели

Все 18 моделей были переэкспортированы с флагом `--force`:

```bash
python scripts/export_models_onnx.py --format onnx --force
```

**Результат**: ✅ Успешно экспортированы 18/18 моделей

### 3. Проверка динамического размера

**До исправления** (фиксированный размер):
```
Shape: 1 3 960 960
```

**После исправления** (динамический размер):
```
Shape: batch 3 height width
```

Теперь модели поддерживают:
- ✅ Любой размер батча
- ✅ Любую высоту изображения
- ✅ Любую ширину изображения
- ✅ 3 канала (RGB) - фиксировано

## Преимущества динамического размера

### 1. Гибкость использования
Одна ONNX модель может работать с разными размерами входа:
```python
# Все эти размеры теперь работают:
model.predict(img, imgsz=608)   # ✅
model.predict(img, imgsz=640)   # ✅
model.predict(img, imgsz=960)   # ✅
model.predict(img, imgsz=1280)  # ✅
```

### 2. Батч-инференс для классификации
Классификационные модели теперь могут обрабатывать несколько изображений за раз:
```python
# Обработка 8 кропов одновременно
results = model.predict(crops_batch)  # shape: [8, 3, 32, 32]
```

### 3. Совместимость с PyTorch
ONNX модели теперь ведут себя так же, как PyTorch модели:
- Поддерживают любой `imgsz` параметр
- Работают с батчами переменного размера
- Не требуют изменения кода при переключении backend

## Недостатки и компромиссы

### 1. Немного меньшая производительность
- Динамические модели могут быть на 5-10% медленнее фиксированных
- Оптимизации компилятора менее агрессивны для динамических размеров

### 2. Больший размер модели
- Динамические модели могут быть немного больше по размеру
- Содержат дополнительную информацию для обработки переменных размеров

**Но эти недостатки несущественны по сравнению с преимуществами гибкости!**

## Для OpenVINO

OpenVINO модели также экспортируются с `dynamic=True`, что позволяет:
- Использовать разные размеры входа
- Оптимизировать производительность на Intel CPU
- Поддерживать батч-инференс
