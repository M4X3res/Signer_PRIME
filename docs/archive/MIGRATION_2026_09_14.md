### 🔒 Лицензирование
**ВАЖНО:** Приложение больше НЕ работает офлайн несколько дней!

**Было:**
- Grace period 3 дня — можно было работать без интернета
- Проверка лицензии: локально → если просрочен → фоновое обновление

**Стало:**
- **Обязательная онлайн-проверка** при каждом запуске
- Без подключения к серверу лицензий → приложение не запустится
- Блокирующий диалог с кнопками "Повторить"/"Отмена"

**Для разработки:**
```bash
# Запустите локальный dev-сервер лицензий
cd signer-license-server
python -m uvicorn app.main:app --reload

# В другом терминале
set SIGNER_LICENSE_SERVER_URL=http://localhost:8000
python main.py
```

## Миграция для других разработчиков

1. **Удалите локальный токен** (если хотите протестировать активацию):
   ```
   del %LOCALAPPDATA%\Signer\license.token
   ```

2. **При запуске без интернета** увидите диалог:
   ```
   Не удалось подключиться к серверу лицензий.
   Проверьте интернет-соединение.
   [Повторить] [Отмена]
   ```

3. **Для разработки** используйте локальный сервер (см. выше)
