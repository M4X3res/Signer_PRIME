# Исправление краша при нажатии на кнопку GeoJSON

## Проблема

При нажатии на кнопку "↓ GeoJSON" программа вылетает с кодом:
```
Process finished with exit code -1073740791 (0xC0000409)
```

**Код ошибки:** `0xC0000409` = `STATUS_STACK_BUFFER_OVERRUN`

## Причины

1. **Конфликт потоков**: Flask-SocketIO + Qt WebEngine + OpenMP
2. **Проблемы с путями Windows**: некорректная обработка путей с кириллицей
3. **Конфликт логгеров**: одновременный вывод от Flask, SocketIO и Qt

## Исправления

### ✅ 1. Нормализация путей в `api_geojson_export()`
- Добавлен `os.path.normpath()` и `os.path.abspath()`
- Добавлена обработка исключений
- Улучшена диагностика ошибок

### ✅ 2. Отключение логгеров SocketIO
- `logger=False`
- `engineio_logger=False`

### ✅ 3. Улучшенные настройки Flask
- `use_reloader=False`
- `debug=False`
- `host='127.0.0.1'`

### ✅ 4. Обработка ошибок в main.py
- Try-except блок для диагностики

## Тестирование

1. Запустите программу
2. Обработайте видео
3. Откройте карту
4. Нажмите "↓ GeoJSON"
5. Файл должен скачаться без краша
