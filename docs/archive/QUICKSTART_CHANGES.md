### 🎥 3. Видео на карте теперь работает!
**До:** "Video loading timeout (10s)" при клике на знак  
**Причина:** PyQt6-WebEngine без H.264/AAC кодеков  
**После:** Автоматическое транскодирование в WebM через ffmpeg

**Что реализовано:**
- ✅ Новый эндпоинт `/api/video_clip/<video_idx>?start=&duration=`
- ✅ Транскодирование H.264 → VP9+Opus (WebM)
- ✅ Кэширование клипов рядом с видео: `<video>_clip_<start>_<duration>.webm`
- ✅ Graceful degradation при отсутствии ffmpeg

**Установка ffmpeg:**
```bash
# Windows (Chocolatey):
choco install ffmpeg

# Или скачать: https://ffmpeg.org/download.html
# Добавить в PATH
```

**Как проверить:**
```
1. Убедиться что ffmpeg в PATH: ffmpeg -version
2. Обработать видео → Открыть карту
3. Кликнуть на маркер знака → Воспроизведение клипа ✅
4. Повторный клик → Кэш (логи: "Cache hit") ✅
```
