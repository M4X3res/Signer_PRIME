# Инструкция по тестированию исправлений Process Pool / Pipeline

**Цель**: Проверить что краш 0xC0000409 при "Завершить" исправлен

---

## Что исправлено

### Основная проблема
**До**: Блокировка UI + принудительный kill процессов → краш 0xC0000409  
**После**: Graceful shutdown без kill → корректное завершение

### Дополнительные исправления
✅ Preview теперь работает в Process Pool  
✅ Исправлен порядок кадров при нескольких видео  
✅ Исправлен UnboundLocalError в checkpoint resume  
✅ Исправлен print() для windowed сборки

## Быстрый тест (5 минут)

### Шаг 1: Pipeline режим
```bash
python main.py
```

1. Settings → "Pipeline"
2. Загрузить короткое видео + GPX
3. "Начать обработку"
4. **Через 10 секунд** нажать "■ Завершить"

**Ожидается**:
- ✅ НЕТ зависания UI
- ✅ НЕТ краша 0xC0000409
- ✅ GeoJSON создан

### Шаг 2: Process Pool режим
1. Settings → "Process Pool"
2. Загрузить короткое видео + GPX
3. "Начать обработку"
4. **Проверить**: Preview показывает кадры с bbox (не чёрный экран)
5. **Через 50 кадров** нажать "■ Завершить"

**Ожидается**:
- ✅ Preview работает
- ✅ НЕТ краша 0xC0000409
- ✅ В консоли: "Aggregator завершился естественно"
- ✅ В консоли: "Executor закрыт корректно"
- ✅ GeoJSON создан

## Что смотреть в логах

### Успешное завершение Process Pool
```
[DetectorProcessPool] Aggregator завершился естественно — закрываем executor...
[DetectorProcessPool] Executor закрыт корректно
[ProcessingController] Сохранение GeoJSON...
```

### Успешное завершение Pipeline
```
[DetectorThread] Финиш обработки
[OCRPool] Остановка... (обработано N задач)
[OCRPool] Остановлен
[ProcessingController] Сохранение GeoJSON...
```

### Признаки проблемы
❌ `Process finished with exit code -1073740791 (0xC0000409)`  
❌ UI "Not Responding" более 10 секунд  
❌ GeoJSON пустой или не создан  
❌ Висячие python.exe в Task Manager после закрытия

## Если краш всё равно происходит

Соберите диагностику:

### 1. Последние логи
```bash
tail -n 100 roadscan.log
```

### 2. Video debug log (если есть)
```bash
cat video_debug.log
```

### 3. Windows Event Viewer
1. Открыть "Просмотр событий"
2. Windows Logs → Application
3. Найти ошибки около времени краша
4. Скопировать детали

### 4. Task Manager
- Остались ли висячие python.exe процессы?
- Сколько их?

### 5. Точный момент краша
- После какого лог-сообщения произошёл краш?
- Что было последнее в консоли?
