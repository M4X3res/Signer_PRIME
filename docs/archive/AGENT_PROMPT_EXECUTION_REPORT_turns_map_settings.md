#### ✅ 1.3 Условный вызов turn.handle_turn()
**Файл:** `core/sign_handler.py:382-395`

```python
def _handle_turn_end(self, turn, current_frame: int):
    if turn.signs and len(turn.coordinates) >= 2:
        turn.add_points()
        self._remove_lost_signs(current_frame)
        self.signs, turn.signs = self._separate_turn_signs(turn)
        turn.set_direction_signs()
        # BLOCK 1.3: вызываем handle_turn() только если bearing-геометрия отключена
        # (в bearing-режиме результат не используется)
        from configs.settings import get_app_settings
        settings = get_app_settings()
        if not settings.turn_use_bearing_geometry:
            turn.handle_turn()
        self.turns.append(copy.copy(turn))
    turn.clean()
    return turn
```

**Результат:** Эвристика `handle_turn()` теперь пропускается в bearing-режиме (дефолт), экономя CPU.

### Критерии приёмки (выполнено)

- ✅ GPXHandler создаётся не более одного раза за обработку видео
- ✅ `turn.handle_turn()` вызывается только при `turn_use_bearing_geometry = False`
- ✅ Поведение не изменилось (чистый перформанс-фикс)
- ⚠️ Замеры через `profiler.py` не проводились (требуется тестовый ролик)

### Ожидаемый эффект

На видео с 5000 обработанных кадров и GPX на 3000 точек:
- **До:** ~5000 полных парсингов GPX (O(n×m) где n=кадры, m=точки трека)
- **После:** 1 парсинг GPX (O(m))
- **Ускорение:** Кратное (порядок величины) на длинных треках
