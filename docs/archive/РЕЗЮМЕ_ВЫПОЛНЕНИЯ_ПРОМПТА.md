### 🔴 Критичный баг (BUG-1) - ИСПРАВЛЕН

**Проблема:** Весь основной пайплайн классификации знаков (99% вызовов моделей) 
использовал `model(crop)` вместо `model.predict(crop)`. Исправление device='cpu' 
работало только для predict(), поэтому ONNX-бэкенд фактически не работал для 
реальной классификации - продолжались попытки использовать CUDA даже в CPU режиме.

**Теперь:** `__call__()` делегирует в `predict()`, device='cpu' форсируется везде.
