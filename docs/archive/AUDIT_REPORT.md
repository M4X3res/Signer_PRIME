### ⚠️ 4.2. `.gitattributes` превращает `.txt` файлы в LFS

**Проблема:**  
`.gitattributes` содержит правила:
```
.txt filter=lfs diff=lfs merge=lfs -text
*.txt filter=lfs diff=lfs merge=lfs -text
```

Это заставляет Git LFS трекать **любой** `.txt` файл, включая `requirements.txt`

**Текущий статус:**  
`requirements.txt` в репозитории сейчас — реальный контент (не LFS pointer), но при следующем коммите может превратиться в заглушку

**Риск:**  
У клонов без `git lfs` команда `pip install -r requirements.txt` **гарантированно упадёт**

**Решение:**  
✅ ВЫПОЛНЕНО: Удалить правила `.txt` и `*.txt` из `.gitattributes`

---

### ⚠️ 4.4. `MapPage.stop_server()` не существует

**Проблема:**  
`MainWindow.closeEvent()` вызывает `self.page_map.stop_server()` через `hasattr`-guard, но метод `stop_server` в `MapPage` не определён

**Риск:**  
При закрытии приложения сервер Flask/SocketIO не останавливается, поток `ServerThread` остаётся висеть, мешая нормальному завершению процесса

**Решение:**  
🔧 ТРЕБУЕТСЯ: Реализовать `MapPage.stop_server()` с грациозной остановкой `ServerThread`
