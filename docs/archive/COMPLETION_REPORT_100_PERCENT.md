### 5. ✅ Debounce для фильтра карты
**Файл:** `templates/map.html`

**Проблема:** Фильтр вызывал `renderMarkers()` на каждый введённый символ, что на больших датасетах вызывало лаги.

**Решение:**
```javascript
let filterDebounceTimer = null;

function debouncedApplyFilter() {
  if (filterDebounceTimer) {
    clearTimeout(filterDebounceTimer);
  }
  filterDebounceTimer = setTimeout(applyFilter, 250);
}
```

**Изменение в HTML:**
```html
<input id="filter-input" oninput="debouncedApplyFilter()">
```

**Эффект:** Фильтр применяется с задержкой 250мс после окончания ввода, а не на каждую букву.

### 6. ✅ Замена confirm() на кастомный диалог
**Файл:** `templates/map.html`

**Проблема:** 
- `confirm()` блокирует JavaScript event loop
- Не стилизуется под тёмную тему
- Выглядит как системный диалог Windows

**Решение:**
Реализован `showConfirmDialog(title, message)` — асинхронный неблокирующий диалог:

```javascript
async function deleteSign() {
  const confirmed = await showConfirmDialog(
    "Удалить знак?",
    "Это действие нельзя отменить. Знак будет удалён из GeoJSON файла."
  );
  if (!confirmed) return;
  // ... удаление
}
```

**Особенности:**
- Стилизован под тему приложения (CSS переменные)
- Закрывается по ESC
- Закрывается по клику вне диалога
- Кнопка "Удалить" красная (danger)
- Асинхронный (не блокирует UI)

### 7. ✅ Улучшение формата поля `side`
**Файлы:** `server/map_server.py`, `templates/map.html`

**Проблема:** 
- В GeoJSON хранится как строка `"True"/"False"` (для совместимости)
- На фронтенде парсилось через `String(raw).includes("True")` (хрупко)

**Решение:**

**Backend (`server/map_server.py`):**
```python
# Преобразуем side из строки в bool при отправке в API
side_raw = props.get("side", "")
if isinstance(side_raw, bool):
    side_bool = side_raw
else:
    side_bool = str(side_raw).strip().lower() in ("true", "1", "yes")

result.append({
    ...
    "side": side_bool,  # Теперь bool
    ...
})
```

**Frontend (`templates/map.html`):**
```javascript
function parseSide(raw) {
  if (raw === null || raw === undefined) return "—";
  // Поддержка обоих форматов: bool (новый) и строка (старый)
  if (typeof raw === 'boolean') {
    return raw ? "Левая" : "Правая";
  }
  return String(raw).includes("True") ? "Левая" : "Правая";
}
```

**Эффект:**
- API отдаёт нативный `bool` (чище, JSON-friendly)
- Обратная совместимость со старыми GeoJSON файлами
- Фронтенд корректно обрабатывает оба формата
