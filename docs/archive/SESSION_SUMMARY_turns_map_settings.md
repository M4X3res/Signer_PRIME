## 🧪 Как проверить

### Персистентный кеш OSM
1. Обработайте видео с GPX-треком
2. Проверьте, что рядом с видео создался файл `<video_name>_osm_cache.json`
3. Повторно обработайте то же видео
4. В логе должно быть: `"Используется локальный кеш: N дорог"`

### Статистика bearing
1. Обработайте видео с поворотами
2. В конце обработки в логе появится статистика:
   ```
   ═══ Статистика обработки знаков на поворотах ═══
   Всего знаков: 45
   Геометрия (bearing): 38 (84.4%)
   ```

### OCR настройки
1. Откройте Настройки → Многопоточность
2. Найдите контролы "OCR в отдельном процессе" и "Количество OCR воркеров"
3. Измените значения, сохраните
4. Проверьте экспорт/импорт настроек
