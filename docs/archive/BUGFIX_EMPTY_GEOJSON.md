## Проблемы

### 1. Кнопка "Завершить" остаётся в состоянии "⏳ Завершение..."
После нажатия кнопки "Завершить" она не возвращается в исходное состояние.

### 2. GeoJSON файл пустой после обработки
После завершения обработки GeoJSON не содержит знаков.

---

## Причины

### Причина 1: Кнопка не сбрасывается
**Файл:** `ui/widgets/processing_page.py`

**Проблема:**
```python
def set_active(self, active: bool):
    if not active:
        self._finish_clicked = False
        self.btn_pause.setText("⏸   Пауза")
        # ❌ НЕ СБРАСЫВАЕТСЯ: self.btn_finish.setText()
```

Метод `set_active(False)` вызывается после завершения, но **не сбрасывает текст кнопки** обратно в "■ Завершить".

**Исправление:** ✅ Добавлен сброс текста кнопки.

---

### Причина 2: GeoJSON пустой

**Возможные причины (в порядке вероятности):**

#### A. Не выбрана папка для сохранения результатов ⚠️
```python
# configs/config.py
PATH_TO_GEOJSON: str = ""  # ← ПУСТОЙ!
```

**Симптомы:**
- В логе: `[FinalHandler] ERROR: PATH_TO_GEOJSON пустой!`
- GeoJSON не создаётся вообще

**Решение:** Выберите папку для результатов перед обработкой.

---

#### B. Обработка не нашла ни одного знака

**Симптомы:**
- В логе: `[FinalHandler] Знаков: 0`
- GeoJSON создаётся, но `features: []`

**Возможные причины:**
1. Видео не содержит GPS-трека
2. Видео не содержит дорожных знаков
3. Пороги confidence слишком высокие (все знаки отфильтрованы)
4. Качество видео слишком низкое

**Решение:** См. секцию "Диагностика" ниже.

---

#### C. Ошибка при обработке знаков

**Симптомы:**
- В логе: `[FinalHandler] ОШИБКА в _process_straight_signs: ...`
- Exception/Traceback в логах

**Решение:** Проверьте логи, исправьте ошибку.

---

#### D. Ошибка при сохранении файла

**Симптомы:**
- В логе: `[FinalHandler] ОШИБКА при сохранении файла: ...`
- Нет прав на запись в папку

**Решение:** Выберите папку где есть права на запись.

## Диагностика пустого GeoJSON

### 1. Проверьте логи

```bash
notepad roadscan.log
```

**Ищите строки:**
```
[FinalHandler] save_result вызван:
  - Знаков: 0          ← Если 0 — обработка не нашла знаков
  - Поворотов: 0
  - Путь: ...          ← Должен быть установлен!

[FinalHandler] Обработано X прямолинейных знаков
[FinalHandler] Обработано Y знаков на поворотах
[FinalHandler] После дедупликации: Z features
[FinalHandler] Сохранено Z знаков → path
```

---

### 2. Если "Знаков: 0"

#### Причина A: Нет GPS-трека

**Симптомы:**
- В логе: ошибки GPXHandler
- В UI: координаты не обновляются

**Решение:**
1. Убедитесь что выбран GPX файл
2. Проверьте что GPX синхронизирован с видео (одинаковое время)

---

#### Причина B: Слишком высокие пороги confidence

**Проверьте Settings:**
- conf_side: должен быть 0.4-0.6 (не 0.9!)
- conf_rube: должен быть 0.6-0.8
- conf_cnn: должен быть 0.5-0.7

**Если слишком высокие:**
1. Settings → понизьте пороги
2. Обработайте заново

---

#### Причина C: Видео не содержит знаков

**Проверьте:**
- Есть ли знаки в кадре (визуально)
- Достаточно ли качество видео (не размыто)
- Не слишком ли быстрая езда (знаки мелькают)

**Попробуйте:**
- Обработать отрезок где точно есть знаки
- Снизить frame_step (обрабатывать каждый кадр, не каждый 5-й)

---

#### Причина D: Ошибка в обработке

**В логе:**
```
[FinalHandler] ОШИБКА в _process_straight_signs: ...
Exception: ...
Traceback: ...
```

**Решение:**
1. Скопируйте весь traceback
2. Проверьте что все зависимости установлены
3. Если ошибка в bearing-режиме:
   - Settings → "Геометрическая привязка" = OFF
   - Попробуйте legacy режим

---

### 3. Если файл не создаётся вообще

**Проверьте:**
```bash
# 1. Установлен ли путь?
python -c "from configs import config; print(config.PATH_TO_GEOJSON)"

# Должно вывести путь, не пустую строку!
```

**Если пусто:**
1. Dashboard → выберите папку результатов
2. Проверьте что путь появился на карточке
3. Обработайте заново

**Если путь установлен, но файл не создаётся:**
1. Проверьте права на запись в папку
2. Попробуйте выбрать другую папку (например, Desktop)

## Известные проблемы

### 1. "Завершение..." показывается дважды

**Симптомы:**
- Кнопка меняется на "Завершение..."
- Потом возвращается в "Завершить"
- Потом снова "Завершение..."

**Причина:** Двойной вызов `set_active(False)`.

**Временное решение:** Игнорируйте, функционально всё работает.

---

### 2. Долгое сохранение при большом количестве знаков

**Симптомы:**
- "Завершение..." висит минуты
- В логе: дедупликация занимает много времени

**Причина:** O(n) дедупликация + batch OSM snap для turn signs.

**Нормально:** До 2-3 минут для 500+ знаков.

**Если дольше:** Прервите (Ctrl+C) и проверьте логи на зависание.
