# Быстрая инструкция: Тестирование векторных тайлов

## Тест 1: Обратная совместимость (растровые тайлы)

1. Запустить приложение
2. Открыть **Настройки** → **Карта**
3. Проверить:
   - ✅ Выбран тип "Растровые тайлы (PNG/JPG)"
   - ✅ URL по умолчанию: `https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png`
4. Открыть карту (кнопка "Карта" в главном окне)
5. **Ожидается:** Карта загружается с OpenStreetMap

---

## Тест 2: Переключение на векторные тайлы (api.maps.by)

⚠️ **Требуется токен API:** Получите токен на https://api.maps.by/

1. Открыть **Настройки** → **Карта**
2. Выбрать тип: **"Векторные тайлы (.pbf, Mapbox Vector Tiles)"**
3. Ввести URL:
   ```
   http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=YOUR_TOKEN
   ```
   Замените `YOUR_TOKEN` на ваш реальный токен.
4. Атрибуция: `© maps.by`
5. Max zoom: `18`
6. Нажать **Сохранить**
7. Открыть карту
8. **Ожидается:**
   - ✅ Карта загружается с векторными тайлами api.maps.by
   - ✅ Видны дороги, здания, водоёмы
   - ✅ Цветовая схема тёмная (синие линии, тёмная заливка)
9. Открыть консоль браузера (F12 в окне карты) и проверить:
   ```
   [loadTileLayer] Vector tiles loaded: http://api.maps.by/...
   ```

---

## Тест 3: Валидация URL (мягкое предупреждение)

1. Открыть **Настройки** → **Карта**
2. Выбрать тип: **"Векторные тайлы (.pbf)"**
3. Ввести URL с растровым расширением:
   ```
   https://example.com/tiles/{z}/{x}/{y}.png
   ```
4. Нажать **Сохранить**
5. **Ожидается:**
   - ⚠️ Появляется предупреждение:
     ```
     ⚠️ Вы выбрали векторные тайлы, но URL содержит расширение
     растрового изображения (.png/.jpg).
     
     Векторные тайлы обычно имеют расширение .pbf или .mvt.
     
     Карта может не отображаться корректно.
     ```
   - ✅ Настройки всё равно сохраняются (мягкое предупреждение, не блокирует)

---

## Тест 4: Fallback на OSM при ошибке

### Вариант A: Неверный URL

1. Открыть **Настройки** → **Карта**
2. Выбрать тип: **"Векторные тайлы (.pbf)"**
3. Ввести заведомо неверный URL:
   ```
   http://invalid-server.example.com/tiles/{z}/{x}/{y}.pbf
   ```
4. Нажать **Сохранить**
5. Открыть карту
6. **Ожидается:**
   - ⚠️ В консоли браузера (F12) ошибка:
     ```
     Failed to load map config, using fallback OSM: ...
     ```
   - ✅ Карта отображается с OpenStreetMap (растр)

### Вариант B: Отсутствует библиотека VectorGrid

1. Открыть файл `templates/map.html`
2. Временно закомментировать строку:
   ```html
   <!-- <script src="https://unpkg.com/leaflet.vectorgrid@1.3.0/dist/Leaflet.VectorGrid.bundled.js"></script> -->
   ```
3. Перезапустить приложение
4. Открыть карту
5. **Ожидается:**
   - ⚠️ В консоли:
     ```
     Leaflet.VectorGrid library not loaded
     Failed to load map config, using fallback OSM: ...
     ```
   - ✅ Карта отображается с OpenStreetMap (растр)
6. **Вернуть строку обратно** после теста

## Тест 6: Импорт/экспорт настроек

1. Настроить векторные тайлы (см. Тест 2)
2. Открыть **Настройки** → **Резервное копирование**
3. Нажать **📤 Экспорт**
4. Сохранить файл `settings_export.json`
5. Открыть файл в текстовом редакторе
6. Проверить:
   ```json
   {
     ...
     "map_tile_type": "vector",
     "map_tile_url": "http://api.maps.by/...",
     ...
   }
   ```
7. Изменить `map_tile_type` на `"raster"` в файле
8. Нажать **📥 Импорт** в приложении
9. **Ожидается:**
   - ✅ В UI тип меняется на "Растровые тайлы (PNG/JPG)"

## Устранение проблем

### Карта пустая при векторных тайлах

1. Открыть консоль браузера (F12)
2. Проверить ошибки сети (вкладка Network)
3. Проверить:
   - ✅ Токен API действителен
   - ✅ Порядок координат правильный ({z}/{y}/{x} для api.maps.by)
   - ✅ URL скопирован полностью (включая `?token=...`)

### VectorGrid не загружается

1. Проверить интернет-соединение
2. Открыть консоль браузера (F12)
3. Проверить:
   ```
   GET https://unpkg.com/leaflet.vectorgrid@1.3.0/dist/Leaflet.VectorGrid.bundled.js
   ```
4. Если ошибка 404 или timeout — проверить доступность unpkg.com

### Карта откатывается на OSM при каждой загрузке

1. Проверить логи сервера в терминале приложения
2. Искать строку:
   ```
   ERROR in /api/map_config: ...
   ```
3. Если ошибка в чтении настроек — проверить файл QSettings
