# Как правильно настроить векторные тайлы

## ❌ Частая ошибка: URL конкретного тайла вместо шаблона

### Симптомы
Карта показывает **одинаковые повторяющиеся фигуры** (мозаику) вместо нормальной подложки.

### Причина
Вы вставили ссылку на **один конкретный тайл**, а не **шаблон URL**.

---

## ✅ Правильный URL (с плейсхолдерами)

```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=ВАШ_ТОКЕН
                                                               ^^^^^^^^^^
                                                               Обязательно!
```

**Ключевые элементы:**
- `{z}` — уровень масштаба
- `{y}` — координата строки
- `{x}` — координата столбца

⚠️ **Для api.maps.by порядок:** `{z}/{y}/{x}` (не `{z}/{x}/{y}`!)

---

## ❌ Неправильный URL (конкретный тайл)

```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/9/163/291.pbf?token=ВАШ_ТОКЕН
                                                               ^^^^^^^^
                                                               Конкретные числа!
```

**Что не так:**
- `9` — конкретный уровень масштаба
- `163` — конкретная строка
- `291` — конкретный столбец

**Результат:** Карта будет запрашивать разные тайлы, но всегда получать один и тот же → мозаика.

---

## Как исправить

### Вариант 1: Получить правильный URL от провайдера

1. Зайдите на сайт провайдера (api.maps.by)
2. Найдите документацию API
3. Скопируйте URL-шаблон с плейсхолдерами `{z}/{y}/{x}`

### Вариант 2: Исправить существующий URL

Если у вас есть URL конкретного тайла:
```
http://api.maps.by/.../tile/9/163/291.pbf?token=ABC
```

Замените числа на плейсхолдеры:
```
http://api.maps.by/.../tile/{z}/{y}/{x}.pbf?token=ABC
                                ^^^^^^^^^^^
```

---

## Проверка URL перед сохранением

Приложение **автоматически проверит** ваш URL при сохранении настроек.

### Если URL неправильный:

Вы увидите **блокирующее сообщение:**

```
❌ КРИТИЧЕСКАЯ ОШИБКА: URL не содержит обязательные плейсхолдеры {z}, {x}, {y}

Вы вставили ссылку на ОДИН КОНКРЕТНЫЙ тайл вместо ШАБЛОНА.

Пример НЕПРАВИЛЬНОГО URL (ваш случай):
  http://api.maps.by/.../tile/9/163/291.pbf?token=...

Пример ПРАВИЛЬНОГО URL (с плейсхолдерами):
  http://api.maps.by/.../tile/{z}/{y}/{x}.pbf?token=...

⚠️ Без плейсхолдеров карта будет отображать ОДИНАКОВЫЕ повторяющиеся
   фигуры (мозаику) вместо реальной подложки!

❌ Сохранение отменено. Исправьте ошибки и попробуйте снова.
```

**Действия:**
1. Нажмите "OK"
2. Исправьте URL (добавьте `{z}/{y}/{x}`)
3. Попробуйте сохранить снова

### Если URL правильный:

Вы увидите:
```
✓ Сохранено
```

Настройки успешно применены.

---

## Примеры правильных URL

### api.maps.by (Esri/ArcGIS):
```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=ВАШ_ТОКЕН
```

### Другие Mapbox-совместимые серверы:
```
https://tiles.example.com/{z}/{x}/{y}.pbf?key=API_KEY
```

⚠️ **Внимание:** Порядок `{x}/{y}` может отличаться! Сверьтесь с документацией провайдера.

## Частые вопросы

### Q: Я скопировал URL из примера в документации, почему не работает?

**A:** Возможно, вы скопировали URL **с подставленными координатами** (пример запроса), а не **шаблон URL**.

**Ищите в документации:**
- "URL Template"
- "Tile URL Pattern"
- Строки с `{z}`, `{x}`, `{y}`

**Не копируйте:**
- "Example Request"
- "Sample URL"
- Строки с конкретными числами вместо плейсхолдеров

---

### Q: Как узнать правильный порядок координат?

**A:** Проверьте документацию провайдера:

| Провайдер | Порядок |
|-----------|---------|
| api.maps.by (Esri) | `{z}/{y}/{x}` |
| Mapbox | `{z}/{x}/{y}` |
| OpenMapTiles | `{z}/{x}/{y}` |

Если не уверены — попробуйте оба варианта. Приложение покажет ошибку, если порядок неверный.

---

### Q: Токен правильный, плейсхолдеры есть, но карта всё равно пустая?

**A:** Возможные причины:

1. **Порядок координат неверный** ({x}/{y} vs {y}/{x})
   - Попробуйте поменять местами
   
2. **Токен просрочен**
   - Получите новый токен на сайте провайдера
   
3. **Нет прав доступа**
   - Проверьте подписку/план на сайте провайдера

4. **Прокси выключен** (для Esri-серверов)
   - Включите "Прокси для векторных тайлов" в настройках

---

## Как получить правильный URL для api.maps.by

1. Зайдите на https://api.maps.by/
2. Войдите в личный кабинет
3. Перейдите в раздел "API Documentation" или "Vector Tiles"
4. Найдите "Tile URL Template" или "URL Pattern"
5. Скопируйте строку вида:
   ```
   http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf
   ```
6. Добавьте ваш токен:
   ```
   ?token=ВАШ_ТОКЕН_ИЗ_ЛИЧНОГО_КАБИНЕТА
   ```

**Итоговый URL:**
```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=ВАШ_ТОКЕН
```
