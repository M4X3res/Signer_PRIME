## Гипотезы узких мест (по убыванию вероятности)

### 1. OCR (EasyOCR) - САМЫЙ ВЕРОЯТНЫЙ
- EasyOCR на CPU крайне медленный: 100-500ms на знак
- Если в кадре 2-3 знака с текстом → 300-1500ms только OCR
- **Решение:** Батчинг OCR или отключение для теста

### 2. Множественные YOLO вызовы
- `rube_modal.predict()` - вызывается на КАЖДЫЙ найденный bbox
- `model_dict[category].predict()` - еще один вызов на каждый
- Если 5 знаков в кадре → 10+ вызовов YOLO
- **Решение:** Батчинг (Этап 1 из плана)

### 3. GPU не используется
- Все модели на CPU
- `torch.cuda.is_available()` = False? (нужно проверить)
- **Решение:** Включить CUDA если есть GPU

### 4. Отрисовка preview (draw_boxes + emit_frame)
- QPixmap создание + масштабирование на каждый кадр
- Маловероятно что это основное узкое место, но вклад есть
- **Решение:** Оптимизация или пропуск preview при профилировании
