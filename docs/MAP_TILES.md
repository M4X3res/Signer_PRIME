# Настройка подложки карты

## Обзор

Приложение Signer PRIME поддерживает два типа подложек карты:

1. **Растровые тайлы** (PNG/JPG) — традиционный формат, картинки тайлов генерируются на сервере
2. **Векторные тайлы** (Mapbox Vector Tiles, `.pbf`) — современный формат, геометрия передаётся на клиент и отрисовывается с помощью CSS-стилей

## Растровые тайлы (по умолчанию)

### Описание

Растровые тайлы — это готовые изображения (PNG или JPG), которые загружаются с тайлового сервера по запросу. Каждый тайл соответствует определённому уровню zoom и координатам в сетке.

### Пример URL

```
https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
```

### Плейсхолдеры

- `{s}` — поддомен сервера (a, b, c) для балансировки нагрузки
- `{z}` — уровень zoom (0-22)
- `{x}` — X-координата тайла
- `{y}` — Y-координата тайла

### Популярные провайдеры растровых тайлов

- **OpenStreetMap** (по умолчанию):
  ```
  https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
  ```
  Атрибуция: `© OpenStreetMap`

- **OpenTopoMap** (топографическая):
  ```
  https://{s}.tile.opentopomap.org/{z}/{x}/{y}.png
  ```
  Атрибуция: `© OpenStreetMap contributors, © OpenTopoMap`

- **Stamen Terrain**:
  ```
  https://tiles.stadiamaps.com/tiles/stamen_terrain/{z}/{x}/{y}.png
  ```
  Атрибуция: `© Stamen Design, © OpenStreetMap contributors`

## Векторные тайлы (.pbf)

### Описание

Векторные тайлы передают геометрию объектов (дороги, здания, водоёмы) в сжатом формате Protocol Buffers (`.pbf`). Отрисовка происходит на клиенте с помощью CSS-стилей, что позволяет гибко настраивать внешний вид карты.

### Пример URL

```
http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=YOUR_TOKEN
```

⚠️ **Важно:** Порядок координат в URL может отличаться от растровых тайлов!

### Плейсхолдеры

Векторные тайлы могут использовать разные порядки координат в зависимости от провайдера:

- **Стандартный порядок**: `{z}/{x}/{y}` (как у OSM)
- **Альтернативный порядок**: `{z}/{y}/{x}` (например, api.maps.by)

🔍 **Всегда сверяйтесь с документацией провайдера!** Неправильный порядок координат приведёт к загрузке пустых тайлов или тайлов с неправильных участков карты.

### Токены и параметры

Многие провайдеры векторных тайлов требуют токен аутентификации:

```
http://example.com/tiles/{z}/{x}/{y}.pbf?token=YOUR_API_KEY
```

⚠️ При копировании URL убедитесь, что:
- Все параметры query-string (`?token=...`) скопированы полностью
- Символы `&` между параметрами корректно сохранены
- Специальные символы правильно urlencoded (если нужно)

### Стилизация

Векторные тайлы отрисовываются с универсальным стилем, который подходит для большинства схем:

- **Цвет линий**: синий (#3d8ef0)
- **Цвет заливки**: тёмно-серый (#1c2128)
- **Толщина линий**: 1px
- **Прозрачность заливки**: 30%

Стиль автоматически применяется ко всем слоям векторных тайлов (дороги, здания, водоёмы и т.д.).

## Настройка в приложении

### 1. Откройте настройки

Перейдите на страницу **Настройки** → раздел **Карта**

### 2. Выберите тип подложки

- **Растровые тайлы (PNG/JPG)** — для традиционных тайловых серверов
- **Векторные тайлы (.pbf, Mapbox Vector Tiles)** — для современных векторных серверов

### 3. Введите URL

Вставьте URL-шаблон вашего тайлового сервера с плейсхолдерами `{z}`, `{x}`, `{y}` (и `{s}` для растровых тайлов).

⚠️ **Проверьте порядок координат!** Для некоторых провайдеров (в т.ч. api.maps.by) порядок — `{z}/{y}/{x}`, а не `{z}/{x}/{y}`.

### 4. Укажите атрибуцию

Введите текст атрибуции (обязательно для большинства тайловых серверов):

```
© OpenStreetMap contributors
```

### 5. Установите максимальный zoom

Укажите максимальный уровень приближения карты (обычно 19 для OSM, может быть выше для коммерческих серверов).

### 6. Сохраните настройки

Нажмите **Сохранить** и перезагрузите карту.

## Валидация и устранение проблем

### Предупреждение о несоответствии типа и URL

При сохранении настроек приложение проверяет соответствие выбранного типа подложки и расширения файла в URL:

- **Векторный тип + .png/.jpg в URL** → предупреждение
- **Растровый тип + .pbf/.mvt в URL** → предупреждение

Если вы видите такое предупреждение:
1. Проверьте, что выбран правильный тип подложки
2. Проверьте URL на опечатки
3. Сверьтесь с документацией провайдера

### Карта не отображается

**Возможные причины:**

1. **Неверный порядок координат** (`{x}/{y}` vs `{y}/{x}`)
   - Решение: сверьтесь с документацией провайдера
   
2. **Отсутствует токен или токен недействителен**
   - Решение: проверьте, что токен скопирован полностью и действителен
   
3. **Библиотека VectorGrid не загрузилась** (только для векторных тайлов)
   - Решение: проверьте подключение к интернету при первой загрузке карты
   - Fallback: приложение автоматически переключится на OpenStreetMap (растр)

4. **Неверный URL или недоступный сервер**
   - Решение: проверьте URL на опечатки, откройте консоль браузера (F12) для деталей

### Откат на OpenStreetMap

Если настроенная подложка недоступна, карта автоматически откатывается на растровые тайлы OpenStreetMap:

```
https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
© OpenStreetMap contributors
Max zoom: 19
```

Это гарантирует, что карта всегда будет отображаться, даже если произошла ошибка загрузки настроенной подложки.

## Обратная совместимость

Существующие сохранённые настройки (до добавления поля `map_tile_type`) автоматически интерпретируются как **растровые тайлы**. Никаких дополнительных действий от пользователя не требуется.

## Производительность

### Растровые тайлы

- ✅ Низкая нагрузка на клиент (готовые изображения)
- ❌ Больший объём трафика
- ❌ Фиксированный стиль (заложен в изображениях)

### Векторные тайлы

- ✅ Меньший объём трафика (сжатая геометрия)
- ✅ Гибкая стилизация на клиенте
- ❌ Выше нагрузка на клиент (рендеринг геометрии)

Для большинства случаев разница в производительности незначительна на современных компьютерах.

## Примеры конфигураций

### OpenStreetMap (растр)

```
Тип: Растровые тайлы (PNG/JPG)
URL: https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png
Атрибуция: © OpenStreetMap contributors
Max zoom: 19
```

### api.maps.by (вектор)

```
Тип: Векторные тайлы (.pbf, Mapbox Vector Tiles)
URL: http://api.maps.by/api/vectorTile/VectorTileServer/tile/{z}/{y}/{x}.pbf?token=YOUR_TOKEN
Атрибуция: © maps.by
Max zoom: 18
```

⚠️ Обратите внимание на порядок координат: **{z}/{y}/{x}**, а не {z}/{x}/{y}!
