# Отчёт: Исправление загрузки векторных тайлов и диагностика

**Дата:** 2026-09-15  
**Статус:** ✅ Выполнено

## Проблема

После реализации поддержки векторных тайлов пользователи сообщали, что подложка не отображается — карта показывает пустой/чёрный фон или молча откатывается на OSM без объяснений. Текущая реализация не давала достаточно диагностики для понимания причины сбоя.

**Возможные причины:**
- Сетевые ошибки (неверный URL, таймаут)
- Ошибки авторизации (невалидный/просроченный токен)
- CORS-блокировка браузером
- Несовместимость формата тайлов (Esri vs Mapbox)
- Битый/склеенный токен пользователя

### ✅ Задача 1 — Диагностика (реализована в коде)

**Файл:** `templates/map.html::loadTileLayer()`

### ✅ Задача 3c — Валидация токена в настройках

**Файл:** `ui/widgets/settings_page.py::_check_tile_url_mismatch()`

Добавлена проверка на подозрительные паттерны в URL:

1. **Пробелы в URL** — часто результат неправильного копирования
2. **Символ `*`** — признак склеенных токенов
3. **Дублирование `token=`** — несколько параметров токена
4. **Двойной амперсанд `&&`** — ошибка копирования

При обнаружении показывается предупреждение:
```
⚠️ В URL обнаружены подозрительные символы: пробелы, символ '*'.

Пожалуйста, проверьте:
• Токен скопирован полностью и без лишних символов
• Нет дублирования параметра token=
• Нет пробелов и специальных символов

Некорректный токен приведёт к ошибкам загрузки карты.
```

## Инструкция по диагностике

### Шаг 1: Открыть DevTools

1. Запустить приложение
2. Открыть страницу Карты
3. Нажать кнопку **"⬡ В браузере"** (откроется в Chrome)
4. Открыть DevTools (F12)

### Шаг 2: Проверить логи консоли

Искать сообщения:
```
[loadTileLayer] Config loaded: {tile_type: "vector", tile_url: "...", max_zoom: 18}
[loadTileLayer] Creating vector tile layer...
[VectorGrid] Tile load start: {coords: {x: 163, y: 291, z: 9}, url: "..."}
[VectorGrid] Tile loaded: {x: 163, y: 291, z: 9}
```

**Если видны ошибки:**
```
[VectorGrid] Tile error: {coords: {...}, error: "...", tile: {...}}
[VectorGrid] Failed tile URL: http://api.maps.by/.../tile/9/163/291.pbf?token=...
```

### Шаг 3: Проверить вкладку Network

1. Перейти на вкладку **Network** в DevTools
2. Перезагрузить карту (Ctrl+R)
3. Фильтр: `tile` или `.pbf`
4. Проверить:
   - **Статус-код:** 200 (OK) / 401 (Unauthorized) / 403 (Forbidden) / 404 (Not Found)
   - **Response Headers:** наличие CORS-заголовков
   - **Preview:** бинарные данные (протокол protobuf)

### Шаг 4: Проверить URL напрямую

Скопировать URL из `[VectorGrid] Failed tile URL:` и открыть в новой вкладке браузера (или через `curl`):

```bash
curl -I "http://api.maps.by/api/vectorTile/VectorTileServer/tile/9/163/291.pbf?token=YOUR_TOKEN"
```

**Ожидаемый результат:**
```
HTTP/1.1 200 OK
Content-Type: application/x-protobuf
```

**Если 401/403:**
- Токен невалидный или просрочен
- Проверить права доступа в личном кабинете провайдера

**Если CORS-ошибка:**
```
Access to fetch at '...' from origin 'http://127.0.0.1:3000' has been blocked by CORS policy
```
→ Активировать прокси (см. раздел "Активация CORS-прокси")

### Шаг 5: Проверить токен в настройках

Открыть **Настройки** → **Карта** и проверить:
- ✅ Токен скопирован полностью
- ✅ Нет лишних пробелов до/после
- ✅ Нет символа `*` (склеенные токены)
- ✅ Только один параметр `token=`

## Известные ограничения

### Esri ArcGIS Vector Tile Server

Если URL содержит сегмент `VectorTileServer` (например, api.maps.by), это **Esri ArcGIS REST API**, а не чистый Mapbox Vector Tiles.

**Потенциальные проблемы:**
- Имена слоёв могут не совпадать с ожидаемыми (`'*'` fallback должен покрыть это)
- Формат protobuf может отличаться от спецификации Mapbox
- Может потребоваться другой рендерер (не `Leaflet.VectorGrid`)

**Диагностика:**
1. Проверить эндпоинт стилей:
   ```
   http://api.maps.by/api/vectorTile/VectorTileServer/resources/styles/root.json?token=...
   ```
2. Получить список слоёв из поля `layers`
3. Если `Leaflet.VectorGrid` не рисует — потребуется другая библиотека (например, MapLibre GL JS)

**Документировано как известное ограничение:** текущая реализация рассчитана на Mapbox Vector Tiles. Для Esri-специфичных серверов может потребоваться альтернативный рендерер.
