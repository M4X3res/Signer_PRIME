# Сборка установщика

1. Подготовьте настоящий релиз через `scripts/build/prepare_release.bat`.
2. Убедитесь, что в `installer` есть совместимые `7z.exe` и `7z.dll`.
3. Скомпилируйте `installer/SignerInstaller.iss` в Inno Setup 6.7 или новее.
4. Опубликуйте файлы релиза и установщик той же версии. До публикации файлов на GitHub веб-установщик не сможет скачать программу.

Параметры версии и частей архива берутся из `release/installer_release.iss` и `installer_sizes.iss`. Не редактируйте их вручную.

По умолчанию предлагается установка для текущего пользователя с базовыми компонентами. Для CUDA Toolkit, системного FFmpeg и K-Lite выберите режим для всех пользователей. Эти сторонние компоненты не удаляются при удалении Signer. Для обновления Signer в защищённом системном каталоге нужны права записи; рекомендуемый режим установки для текущего пользователя избавляет от этой необходимости.

Архив скачивается сразу в уникальный рабочий каталог внутри выбранной папки установки и распаковывается там же. Например, при установке в `D:\Signer` большие файлы не проходят через временную папку на C. Штатный механизм Inno Setup копирует и регистрирует файлы, после чего рабочий каталог очищается. Он также очищается при обычной ошибке или закрытии мастера; при аварийном завершении процесса папка может остаться. Деинсталлятор удаляет установленные файлы, сохраняя созданные пользователем проекты. Системные переменные TEMP и TMP не меняются.

На системном диске всё равно требуется небольшое место для самого мастера, журналов и обязательного Visual C++ Runtime. Выбранный диск должен вместить архив, распакованную и установленную копии. Сторонние установщики CUDA и кодеков могут иметь собственные требования к системному диску: при ограниченном месте на C выбирайте рекомендуемую установку Signer без этих компонентов.

Генератор дополнительно создаёт `installer_downloads.iss` с контрольными суммами загрузок и `installer_payload.iss` с точным списком устанавливаемых файлов. Загрузка идёт штатным механизмом `[Files]`, а не через `DownloadTemporaryFile`.

Интеграционная проверка небольшим настоящим установщиком из локального HTTP-источника: `.venv/Scripts/python.exe scripts/build/test_installer_workspace.py`. Она проверяет каталог назначения, порядок подготовки файлов и очистку при успехе и повреждённой загрузке.

Проверка компиляции без весов моделей и дистрибутива:

```powershell
& 'C:/Program Files (x86)/Inno Setup 6/ISCC.exe' /DInstallerSmokeTest installer/SignerInstaller.iss
```

Создаваемый `SignerInstaller-COMPILE-TEST-NOT-FOR-DISTRIBUTION.exe` намеренно запрещает установку. Не публикуйте его. Эта проверка не заменяет установку настоящего релиза на чистой Windows, проверку запуска, обновления и удаления. Подписание установщика требует вашего сертификата; цифровая подпись автоматически не создаётся.
