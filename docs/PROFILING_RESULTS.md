## Узкие места (по приоритету)

### 1. OCR (EasyOCR) - 90% вероятность

**Признаки:**
- Огромная разница между кадрами с/без знаков (643ms)
- EasyOCR на CPU: 100-500ms на знак
- Если 20% знаков требуют OCR → средняя задержка ~100-150ms

**Решение:**
- Батчинг OCR вызовов
- Параллелизм (отдельный процесс для OCR)
- Или временно отключить для теста

### 2. Множественные YOLO вызовы

**Проблема:**
- `classify_rube()` - вызывается на КАЖДЫЙ bbox (3-5 раз)
- `classify_fine()` - еще раз на каждый (3-5 раз)
- Итого: 6-10 вызовов YOLO на кадр

**Решение:**
- Батчинг (Этап 1 из PROMPT_MULTITHREADING)
- Ожидаемый прирост: +20-40%

### 3. CNN Кэш не работает

**Критично исправить!**
- Сейчас потеря 30-50% производительности
- После исправления: FPS может вырасти с 0.85 до 1.2-1.5

**Проверить:**
- Включен ли кэш в настройках?
- Работает ли `@lru_cache` декоратор?
- Правильно ли вычисляется хэш изображения?

### 4. GPU не используется

**Проверить:** `torch.cuda.is_available()`
- Если GPU есть но не используется → включить
- CUDA может дать 5-10x ускорение

```python

```

Ожидаемый результат: FPS вырастет до 2-3

### 3. Исправить условие печати отчета

В `processing/detector_thread.py`:
```python
# Было:
if self._frames_processed % config.PROFILING_REPORT_INTERVAL == 0:

# Должно быть:
if self._frames_processed >= self._next_report_at:
    profiler.log_report()
    self._next_report_at += config.PROFILING_REPORT_INTERVAL
```
